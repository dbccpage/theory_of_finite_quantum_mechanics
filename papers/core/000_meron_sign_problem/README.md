# A Lexically Filtered Meron-Cluster Benchmark

Jeremy H. Carroll. Version 0.1.0, 2026-10-02. Preprint, author-review revision.

Full title: "A Lexically Filtered Meron-Cluster Benchmark: Exact Ground Truth,
Mechanized Cancellation Lemmas, and a Pilot That Exposes Answer Leakage".

## What this package is

- `paper.md` (with `paper.tex` and `paper.pdf`): the manuscript.
- `paper_claim_ledger.md`: each claim, its status, and the evidence behind it.
  `paper_change_log.md`: what changed and what was withdrawn.
- `results/`: the retained record of the pilot run, including one output from
  an anonymous model. These files are kept as recorded.
- `lean4/`: Lean 4 proofs of the per-orbit cancellation lemmas.
- `docs/`: dated release-validation and replay records, the finite witness
  protocol, references and figure descriptions.

The oracle, the prompt builders, the scorer, the pilot harness and their tests
are not in this repository. The claim ledger cites each of those files by the
SHA-256 of its bytes (`external:sha256:<hex>`), so a reader holding the code can
check that it is the code the claims were tested against.

The pilot's passing runs received the answer in their prompts, so the package
supports no claim that a model discovered the cancellation mechanism. See
Sections 5 and 6 of the paper.

## How to check it

Build the Lean proofs and replay the axiom census:

```text
cd lean4
lake build
lake env lean Census.lean
```

## Toolchain

Lean 4.35.0 with Lake 5.0.0 (pinned in `lean4/lean-toolchain`).

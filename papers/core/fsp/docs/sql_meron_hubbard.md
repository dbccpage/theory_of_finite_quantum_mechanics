# Exact SQL experiments for Meron and Hubbard models

AuthorityEffect: None.

The executable `code/sign_sql/exact_models.py` now constructs finite signed
ensembles from fermionic operators. The older three-row illustrative SQL fixture
is a separate example. The new evaluator performs relational graph construction,
component discovery, orbit aggregation, auxiliary-field matrix multiplication,
and determinant expansion in SQLite. Its arithmetic extensions are rational
addition, multiplication, division, integer powers, absolute value, sign, integer
popcount, and `qsum`. The latter folds each term into a GCD-reduced Python
`Fraction`; SQLite never decides a weight sign using floating point. There is
no determinant or partition-function UDF. Rational values are TEXT so SQLite's
64-bit integer overflow cannot silently convert a weight to REAL. Native sums
only handle bounded occupancies, masks, cluster counts, and parity counts.

`databases/meron_hubbard.sql` defines the relational schema and audit views.
`code/sign_sql/exact_models_receipt.json` is the deterministic default replay.
It records finite computational evidence, with the precise ensemble indicated.
Each record carries its model parameters and selected support; the top-level
record hashes the evaluator, SQL schema, and focused test source. Audit entry
points reject stale/missing/extra relation keys, including an out-of-domain
orientation substituted without changing its orbit's cardinality.
Meron admission additionally rebuilds the declared model and compares every
relation as a multiset. Coherently deleting an entire graph, replacing all its
weights by a negative value, or fabricating a positive character ensemble thus
fails even if an internal cancellation identity still holds. This costs a
second finite construction; it is separate from the independent occupation
transfer replay used to validate the construction itself.

## 1. Physical Meron model and exact transfer parameters

Chandrasekharan and Wiese's spinless nearest-neighbor Hamiltonian includes the
case

\[
 H=\sum_{\langle xy\rangle}\left[
 -\frac t2(c_x^\dagger c_y+c_y^\dagger c_x)
 +t(n_x-\tfrac12)(n_y-\tfrac12)\right],\qquad t>0.
\]

Their loop construction and meron terminology are the external provenance for
this experiment; their published simulation algorithm additionally controls the
sampling of meron sectors. The present implementation performs finite exact
enumeration and does not implement that sampling algorithm.
[Chandrasekharan–Wiese, PRL 83, 3116 (1999)](https://doi.org/10.1103/PhysRevLett.83.3116).

Take an even periodic chain, split its bonds into even and odd matchings, and
repeat those matchings `M` times. There are `T=2M` occupation time slices and
`P=LM` interaction plaquettes. Set `q=exp(epsilon*t)>=1` rational. Divide each
local transfer matrix by the positive factor `q^(-1/4)`. Its nonzero magnitudes
then are

| Local occupation before/after | Normalized magnitude |
|---|---:|
| `00 -> 00`, `11 -> 11` | `1` |
| `01 -> 01`, `10 -> 10` | `(q+1)/2` |
| `01 -> 10`, `10 -> 01` | `(q-1)/2` |

Hopping entries have the CAR sign
`(-1)^(number of occupied orbitals strictly between the endpoints)` in the
fixed site order. This sign is computed from reconstructed occupations, including
the periodic boundary hop. Thus the negative data are generated by the model.
The calculation is an exact finite checkerboard transfer product. Equality to
the unsplit thermal trace requires a Trotter limit not performed here.

Each plaquette is expanded into a vertical breakup of weight `a=1`, preserving
occupancy along its two temporal edges, or a horizontal breakup of weight
`b=(q-1)/2`, requiring opposite occupancies along the two spatial edges. The
mixed stationary entry is `a+b`; the hopping entry is `b`. A breakup graph is
therefore assigned `W(g)=b^(number of horizontal plaquettes)` before signs.

SQL recursively enumerates breakup choices, computes connected components on
the periodic spacetime graph, and orders components by their smallest node.
The staggered reference occupation is one on even sites and zero on odd sites.
Every component can be flipped. The database reconstructs all `2^k` resulting
occupation configurations, independently evaluates their CAR signs, and tests
the character identity

\[
 s_g(f)=(-1)^{m_g\cdot f},\qquad
 m_{g,j}=\frac{1-s_g(e_j)}2.
\]

It also checks full orbit cardinality and equality of magnitudes. Merely
declaring a meron mask is insufficient for admission. The tests deliberately
alter a sign, alter one magnitude, or delete an orientation and require rejection.

For an admitted orbit the elementary factorization proves

\[
 \sum_f W(g)s_g(f)
 =W(g)\prod_{j=1}^{k}(1+(-1)^{m_{g,j}})
 =2^kW(g)\,\mathbf1_{m_g=0}\ge0.
\]

This is an actual nonnegative orbit representation of this finite transfer
partition function. It establishes the cancellation identity after graph
construction. Exponentially many graphs may still require enumeration.

At `L=4, M=2, q=3`, the exact SQL result is:

| Quantity | Value |
|---|---:|
| Breakup graphs | 256 |
| Expanded orientations | 1296 |
| Negative orientations of positive magnitude | 192 |
| Zero-meron graphs | 199 |
| Signed normalized partition sum | 912 |
| Absolute normalized partition sum | 1296 |
| Average sign before orbit cancellation | `19/27` |
| Nonnegative orbit partition sum | 912 |
| Independent occupation-transfer trace | 912 |

The positive scalar removed from the partition function is `q^(-P/4)`. Thus
this instance's unnormalized finite checkerboard trace is `912/9=304/3`.
The independent trace uses local occupation transfer operators and never reads
cluster labels or signs from the SQL cluster evaluator.

## 2. Observables need their own cancellation rule

For any function `A(f)` on a certified orbit, define its Boolean Fourier
coefficient by

\[
 \widehat A(m)=2^{-k}\sum_f A(f)(-1)^{m\cdot f}.
\]

The signed observable numerator is exactly `2^k W(g) Ahat(m_g)`.
Consequently a zero partition contribution does not justify deleting that
orbit from every observable calculation.

The implemented observable is the squared staggered spacetime occupation,
with the common `epsilon` factor removed:

\[
 O(f)=\sum_{(x,\tau)}(-1)^x(n_{x,\tau}(f)-\tfrac12)
     =\sum_j a_j(-1)^{f_j},\qquad a_j=|C_j|/2.
\]

Expanding the square and using character orthogonality gives an improved
average of `sum_j a_j^2` in the zero-meron sector, `2a_i a_j` when the meron
set is `{i,j}`, and zero otherwise. SQL computes that expression and separately
folds `sign * weight * O^2` over every orientation. Both give **36864**, so
`<O^2>=36864/912=768/19`. Tests require a two-meron orbit with zero partition
weight and a strictly positive squared-observable numerator.

## 3. Hubbard occupation Hamiltonians and gauge obstruction

For the ordinary spinful Hubbard Hamiltonian

\[
 H=-t\sum_{\langle ij\rangle,\sigma}
 (c_{i\sigma}^\dagger c_{j\sigma}+\mathrm{h.c.})
 +U\sum_i n_{i\uparrow}n_{i\downarrow}
 -\mu\sum_{i,\sigma}n_{i\sigma},
\]

the occupation constructor uses the orbital order
`up_0,...,up_(L-1),down_0,...,down_(L-1)`. It enumerates a selected
`(N_up,N_down)` sector and creates each Hamiltonian matrix element directly
from CAR hopping and diagonal interactions. It rejects duplicate undirected
bonds and approximate coefficients.

Let `a_xy=-sign(H_xy)` for a nonzero off-diagonal element. A diagonal sign
gauge `d_x` makes all such entries nonpositive precisely when
`d_y=a_xy d_x` is consistent. SQL computes reachability in the signed double
cover `(basis_state,+/-1)`. A reachable `(x,-1)` from `(x,+1)` is an obstruction;
otherwise the minimum-root component supplies a reconstructible gauge. A
shortest negative closed walk is reconstructed from the same finite edge
table. Tests independently multiply its edge signs.

For four sites, `N_up=2,N_down=1,U=4,t=1,mu=0`, all examples have 24 basis
states and both zero and nonzero interaction diagonals:

| Physical hopping graph | Diagonal sign gauge | Negative cycle in integer Fock masks |
|---|---|---|
| Open path `01,12,23` | Exists; all signs `+1` | None |
| Periodic ring `01,12,23,03` | Obstructed | `19,21,22,26,19` |
| Three-leaf star `01,02,03` | Obstructed | `19,22,21,28,25,26,19` |

The star is a physical tree but its many-particle configuration graph admits
exchange loops. A physical graph having no cycles therefore does not establish
the absence of a fermion sign obstruction. The obstruction excludes this
particular diagonal sign gauge; it excludes neither determinant regrouping nor
other representations.
The half-filled `(N_up,N_down)=(2,2)` ring also has a negative configuration
cycle, while the auxiliary representation below has paired nonnegative weights
throughout its protected sector. Gauge obstruction depends on off-diagonal
hopping signs and is independent of the diagonal value of `U`.

## 4. Exact Hubbard auxiliary-field representation

The determinant lane uses the particle-hole-centered interaction
`U(n_up-1/2)(n_down-1/2)` and shifted chemical potential `mu`. Ordinary Hubbard
parameters satisfy `mu_ordinary=mu+U/2`, with an overall constant `U*L/4`.

For every bond, use its exact single-particle hopping exponential with rational
`r=exp(delta_tau*t/2)>0`. Its two-site block is

\[
 R_{ij}(r)=\begin{pmatrix}(r+r^{-1})/2&(r-r^{-1})/2\\
 (r-r^{-1})/2&(r+r^{-1})/2\end{pmatrix}.
\]

Apply bonds in lexicographically sorted order and then reversed order. The
resulting kinetic matrix `T` is real symmetric positive definite, has determinant
one, and is a palindromic product of exact bond exponentials. Every bond has two
half-time factors. This is a kinetic Suzuki product for the stated Hubbard
hopping graph, not an assertion that a linearized kinetic matrix has an exact
inverse symmetry.

Set `h=exp(lambda)>=1` and `z=exp(delta_tau*mu)>0` rational, with

\[
 \cosh\lambda=(h+h^{-1})/2=e^{\delta\tau|U|/2},\quad
 C=e^{-\delta\tau|U|/4}/2.
\]

For repulsive `U`, the site identity is

\[
 e^{-\delta\tau U(n_\uparrow-1/2)(n_\downarrow-1/2)}
 =C\sum_{s=\pm1}h^{s(n_\uparrow-n_\downarrow)}.
\]

For attractive `U=-|U|`, replace the exponent by
`s(n_up+n_down-1)`. The latter requires the positive field-dependent scalar
`h^(-sum s)` after factorization into spin determinants; the evaluator includes
it. Both lanes omit only the common positive scalar `C^(L*M)`.

SQL enumerates field masks with bit `time*L+site` encoding `(s+1)/2`. Each
time step multiplies relational matrix entries to form
`P_sigma=B_(M-1),sigma ... B_0,sigma`, with `B=T V` and
`V_up=z diag(h^s)`. Repulsive down potentials are `z diag(h^-s)`; attractive
down potentials equal the up potentials. Determinants of `I+P_sigma` are
computed by a recursive CTE that appends unused columns, multiplies exact
entries, and flips sign according to the new inversions. `qsum` folds terminal
permutation terms. This implementation deliberately favors an inspectable
independent formula over large-lattice efficiency.

The protected determinant sectors are consistent with the symmetry criteria
in [Wu–Zhang, PRB 71, 155115 (2005)](https://arxiv.org/abs/cond-mat/0407272).
The finite matrix identities below are verified directly in this package.

For a bipartite hopping graph let `eta` be its diagonal sublattice signs.
Each bond obeys `eta R eta=R^-1`; the palindrome gives `eta T eta=T^-1`.
At `z=1`, symmetry and time ordering yield

\[
 \eta P_\downarrow\eta=(P_\uparrow^T)^{-1},\quad
 d_\downarrow=\frac{d_\uparrow}{\det P_\uparrow},\quad
 \det P_\uparrow=h^{\sum s}>0.
\]

Hence `d_up*d_down=d_up^2/h^(sum s)>=0`, including zero determinants.
For attractive spin-balanced fields the two matrices are identical and the
field weight is `h^(-sum s)*d_up^2>=0`, including away from half filling or on
a frustrated graph. These identities do not assert a mixing-time bound.

Exhaustive default replays verify all **256** fields of the four-site bipartite
ring with two slices, `r=3/2,h=2,z=1`, and all **64** attractive fields of the
three-site triangle with two slices, `r=3/2,h=2,z=3/2`. Both average signs are
exactly one. A separate dense occupation-space transfer calculation for two
sites and two slices reconstructs the entire auxiliary-field sum, including
the attractive scalar:

| Interaction, `r=3/2,h=2,z=3/2` | Direct Fock trace = SQL field sum, with global `C^4` removed |
|---|---:|
| Repulsive | `172283601361/21233664` |
| Attractive | `180365586961/21233664` |

The determinant CTE also propagates its logarithmic fugacity derivative by the
product rule. Since every `M`-slice product satisfies `P(z)=z^M P(1)`, its matrix
entry derivative is `z dP_ij/dz=M P_ij`. Differentiating the two spin determinants,
including their product, gives the exact number numerator

\[
 N_{\rm num}=\frac1M\,z\frac{d\widetilde Z}{dz},\qquad
 \langle N\rangle=N_{\rm num}/\widetilde Z.
\]

No matrix inverse or division by an individual field determinant is required;
zero determinants therefore cause no singular estimator step. The two-site
full-Fock replay independently weights each diagonal trace entry by its particle
number and agrees with the SQL numerator, for both interaction signs. The
four-site protected repulsive ensemble has exactly **`<N>=4`**. The attractive
doped triangle has
`<N>=1776585892008474078571024122583556/557308765039728024001166872319977`.
Selected witness subsets are not assigned a full-ensemble particle-number
expectation.

## 5. Explicit negative fields outside the protected sectors

For the four-site ring with four slices, `r=2,h=8,z=2`, field mask **15721**
gives

\[
 d_\uparrow=\frac{11072073737867929807204939234025}{2305843009213693952}>0,
 \qquad
 d_\downarrow=\frac{-1034021712177776419381618902295}{147573952589676412928}<0.
\]

For the repulsive triangle with four slices, `r=2,h=8,z=1`, mask **1281** gives

\[
 d_\uparrow=\frac{2661572208368287551525625}{9223372036854775808}>0,
 \qquad
 d_\downarrow=\frac{-323903084369592224375}{35184372088832}<0.
\]

These witnesses were found among 256 masks selected without replacement using
Python `random.Random(230923)`, separately from the ascending populations
`range(2^16)` and `range(2^12)`. The permanent replay checks the stated masks
directly and its receipt labels them **selected fields only**. Its
`selected_subset_average_sign=-1` is solely the selected singleton's average;
`full_ensemble_average_sign` is null. Tests independently replay each SQL determinant using a Python
Leibniz expansion. A negative field disproves pointwise positivity for this
specified auxiliary-field representation. It does not prove that the model
lacks every possible sign-free representation.

## 6. Costs, boundary and replay

For `P` meron plaquettes and `k_g` clusters, graph enumeration costs at least
`2^P`, and full validation expands `sum_g 2^k_g` orientations. Orbit evaluation
is linear in the supplied clusters after validity is established. The current
finite driver supports four or six sites and at most twelve plaquettes.

For `L` Hubbard sites and `M` slices, exhaustive fields number `2^(LM)`.
Relational dense products require order `M L^3` arithmetic operations per
field; the transparent determinant recurrence here has `L!` terminal terms.
The signed-double-cover gauge check is finite reachability; it concerns only
the selected occupation basis and selected diagonal gauges. Neither using SQL
nor producing nonnegative rows prices away construction, enumeration, rational
bit growth, observable estimation, or Monte Carlo mixing.

Both physical transfer constructions use finite Trotter/Suzuki products.
These exact rational receipts provide no numerical bound on the difference
from `Tr exp(-beta H)` at fixed discretization. No generic Hubbard or generic
fermion sign problem is solved. What is established is model-derived finite
Meron cancellation with an observable estimator, exact reconstruction of
known protected Hubbard determinant sectors, and concrete obstruction
witnesses when the specified protection is removed.

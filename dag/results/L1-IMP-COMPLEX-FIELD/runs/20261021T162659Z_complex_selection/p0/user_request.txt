## Mathematical target
Work in finite dimension throughout, with exact arithmetic only.

**Carrier family (the declared import).** For K ∈ {ℝ, ℂ, ℍ}, the state/effect space of an n-level
system is the real vector space Herm_n(K) of K-self-adjoint n×n matrices, with
dim_ℝ Herm_n(K) = n + d·n(n−1)/2 for d = 1, 2, 4.

Record the restriction to these three carriers as an IMPORT: Jordan–von Neumann–Wigner /
Koecher–Vinberg, plus the exclusion of spin factors and the exceptional algebra. Do not derive it.
Use exact stand-ins: ℚ for ℝ, ℚ(i) for ℂ, the rational Hamilton quaternions for ℍ. Real completeness
stays an import.

**Operational premise (supplied, not derived).** This is the local tomography already used by
TENSOR-TOMOGRAPHIC-COORDINATES. A composite of systems A and B in the same family has a joint space
spanned by products. Equivalently, the real dimension is multiplicative:

  K_d(nm) = K_d(n) · K_d(m)   for all n, m ≥ 2.

**T1 (dimension selection).** Prove in Lean, over ℕ, with d a parameter, that K_d(nm) = K_d(n)·K_d(m)
for all n, m ≥ 2 if and only if d = 2. Give the explicit failing pairs:
- d = 1, n = m = 2: 3·3 = 9 ≠ 10;
- d = 4, n = m = 2: 6·6 = 36 ≠ 28.

Also prove the one-directional version: a single failing pair suffices to refute d.

**T2 (real QM fails local tomography, exact witness).** Over ℚ, give an explicit symmetric operator
on ℚ²⊗ℚ² that is orthogonal, in the trace pairing, to every product of real symmetric matrices.
This is Y⊗Y with Y = [[0,−1],[1,0]]: it is real and symmetric, while each factor is antisymmetric.
Exhibit two distinct joint real states with identical statistics on every local product test.
Kernel-check the orthogonality and the state distinction.

The valid control is the Gaussian-rational case, where products of ℚ(i)-Hermitian matrices span
Herm_4(ℚ(i)). Reuse `TensorTomography.product_span` if it applies; otherwise prove the n = m = 2
instance.

**T3 (quaternionic composite obstruction).** Show exactly why the same-family quaternionic composite
fails. Either the K_4 count fails (T1), or the product map Herm_2(ℍ) × Herm_2(ℍ) → Herm_4(ℍ) is not
well-defined or bilinear over ℝ in the required sense. State precisely which, and over the rational
quaternions. If it fails only under one composite definition, record both definitions.

**T4 (conditional discharge).** Package T1–T3 into the statement:

  "Under the declared carrier classification (import) and local tomography for same-family composites
  (supplied operational premise), the scalar field of the carrier is ℂ (finite stand-in ℚ(i))."

State exactly which imports remain. Write the node delta for L1-IMP-COMPLEX-FIELD: proposed status
CONDITIONAL, never PROVED_LEAN, because the classification and local tomography are supplied.

**T5 (near misses for P4, mandatory semantic mutants).**
- Real QM with an added complex structure J, i.e. Stueckelberg's real formulation: show that it
  restores local tomography only by reintroducing ℂ, and say what the checker sees.
- Spin-factor carriers V_k: give the dimension count and why the import excludes them. If you cannot
  exclude them, record that as OPEN, not hidden.
- A mutant that drops the n, m ≥ 2 quantifier to n = 1, where every d passes.
- A mutant that claims d = 2 from one passing pair, e.g. a single instance check presented as the
  iff.

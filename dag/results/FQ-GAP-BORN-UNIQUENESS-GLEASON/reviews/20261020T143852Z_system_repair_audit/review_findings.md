# Review findings and fixes

The four accepted Lean sources were read against their actual definitions and are copied byte-for-byte into this audit. No false theorem or fudged numerical value was found in their stated scopes. The parameterized three-ball witnesses use exact real field arithmetic, not decimal tolerances. The old unsafe globals remain archival inputs, and are absent from every accepted import list.

1. **Publication custody failure prevented.** Repository-wide `*.lean`/`*.py` text normalization would alter CRLF-bearing sealed bytes on staging. A narrow result-subtree Git attribute now preserves raw research evidence, including original captured whitespace. Publication checks compare every staged/committed blob to its sealed bytes. Captured evidence whitespace is exempted; newly authored source/report whitespace is checked separately.
2. **Assumption visibility corrected.** Several operation summaries omitted premises or merged two differently conditioned statements (notably the arithmetic counting/tag selector, singleton/full-span regression, and classical/qubit geometry transport). Updated operation records include exact Lean signature receipts and explicit per-proof premise notes. The [assumption ledger](assumptions.json) distinguishes declared real topology/full effects, input-contract fields, and theorem premises. A clean `#print axioms` report is not advertised as hypothesis-free reconstruction.
3. **Replay tooling repaired.** The original compiler helper used fixed machine paths, and its finalizer depended on Python `assert` for validation. The review uses a configurable source-only replay runner and explicit exceptions that remain active under optimized Python. Existing compiled local reconstruction artifacts are not used in the fresh build. The installed Mathlib dependency cache remains an explicitly recorded trust boundary.
4. **Nonvacuity and negative regression added.** `SystemAudit.lean` supplies a concrete rank-one/dimension-one compact convex System, proves its spectrality and strong symmetry, and separately rejects any spectral rank-one/dimension-two phantom without a Jordan catalogue or classification input.
5. **Operad ceiling retained.** Fifteen inherited records contain fourteen collections of checked operations plus one uninstantiated classification contract. That contract is not counted as a proved operation. The added audit witness record is also scoped explicitly. Only the unary affine substitution fragment has formal unit and associativity equations; a full many-arity operad remains open.
6. **Historical scope kept literal.** The dependency closure includes the earlier provider run and proof submissions because later manifests refer to them. They are published as immutable history, including failed attempts and rejected claims. This focused review does not re-prove every historical mathematical claim or run a new model inference.

No catalogue instance, Jordan classification proof, operational tomography derivation, complex-field selection, tensor coherence, or dynamics/process equivalence is established by this review. In particular, `rank_two_dim_four_ball` needs a catalogue representation whose qubit-chart field already supplies the ball geometry. The nonpolytope marginal theorem itself is proved for actual affine geometry without any classification bridge.

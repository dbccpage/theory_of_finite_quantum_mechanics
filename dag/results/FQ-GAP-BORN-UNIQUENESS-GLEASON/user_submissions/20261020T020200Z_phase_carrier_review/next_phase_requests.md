# Five small phase-carrier proof requests

PC namespace; requested proofs are not Lean certificates. These targets correct the submitted chain. Some already have written sketches in review.md and need explicit formal statements/proofs.

PC-1. Colimit: for n|m define Z/nZ -> Z/mZ by [k] -> [(m/n)k]. Prove the directed colimit is Q/Z using [k] -> [k/n]. State the universal property and separate the abstract group statement from any topology or complex embedding.

PC-2. Exact-order hypothesis: let G be a subgroup of C^times containing an element of exact order n for every n>=1. Prove mu_infinity is contained in G. If G is generated by these roots, prove equality. If F is a subfield containing G, prove Q(mu_infinity) is contained in F. Identify all operational assumptions; do not infer the exact-order premise from ordinary divisibility.

PC-3. Divisibility countermodel: prove Z[1/2]/Z is divisible by every positive integer, contains an element of order 4 and has no element of order 3. Give an explicit formula using n=2^s m, m odd, and a modular inverse. Explain why this refutes the original root-closure implication.

PC-4. Completion: let G be a dense subgroup of the standard U(1), complete in its inherited metric. Prove G=U(1). Let F be a subfield of C containing Q(i), complete in the ordinary complex metric. Prove F=C. Identify exactly which topology and completeness assumptions are inputs rather than finite operational consequences.

PC-5. Dimension discriminator: derive K_R(n), K_C(n), K_H(n) for unnormalized self-adjoint matrices. Under the stated composite-size rule N_AB=ab, prove the three multiplicativity-defect formulas in review.md. State why this excludes two candidates only within that model class and does not prove uniqueness among all locally tomographic theories.

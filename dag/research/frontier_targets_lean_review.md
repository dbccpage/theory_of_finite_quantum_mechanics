# Review of the 14 frontier target promotions (OPEN to PROVED_LEAN)

Scope: the 14 finite target nodes that PR 171 (branch `gemini/frontier-targets-lean`) promoted from OPEN to PROVED_LEAN, with the Lean modules of the `FrontierTargets` library. PR 171 and PR 173 were merged into main while this review was running, so the corrections below are a follow-up on top of main (branch `review/frontier-honesty`); the Lean modules were rebuilt on the merged tree, including the PR 173 change to `CausalOrder.lean`. Reviewed against the statements as they stand on main after the frontier source audit (#168). Rule applied: a node may carry PROVED_LEAN only if Lean declarations in the repository state the node's full statement and compile with only propext, Classical.choice and Quot.sound.

Method: each module was read in full; the theorems that discharge the node were identified; the conjunction of those theorems was compared with the node statement. Every module was rebuilt with Lean 4.35.0 (one `lake build <Module>` at a time, read-only junction `lean4/.lake/packages` to the shared Mathlib cache, removed afterwards) and the `#print axioms` output of every printed declaration was checked. Counts that the branch stated in prose were recomputed independently in Python with exact fractions.

Result: 3 nodes FULL, 11 NARROWED, 0 REVERTED. In every narrowed case the node statement now says exactly what is proved and the remainder is in `bottleneck` and in the paper note's `open` list. No node was raised.

Corrections to the branch's own text (statements that contradicted the Lean they cite):

- ADS-HAPPY-ENTROPY-MINCUT-TARGET: the branch text said S(A) equals the minimal bond cut on all 380 intervals. The Lean theorem says S(A) = mincut(A) on 340 and S(A) = mincut(A) - 1 on 40 (this is also what main's audit recorded). Corrected.
- LQG-PR-ALLOWED-REGION-TARGET: the branch text said 10,825 admissible tuples, 9,854 allowed and 971 forbidden. The Lean theorem, and an independent exact recomputation with the bordered 5x5 Cayley-Menger determinant, give 13,691 admissible tuples, 10,884 allowed, 2,807 forbidden and 0 flat. Corrected.
- ADS-FIVE-QUBIT-PERFECT-TENSOR-TARGET: the branch text said 192 nontrivial logical operators; the Lean theorem counts 48 (modulo phase). Corrected.
- CT-QUBIT-NO-CLONING-FINITE-TARGET: the entry of the clone-defect matrix is -1/2 (the branch and main said 1/2). Corrected.
- CT-SUPERINFORMATION-MEDIUM-DEFINITION (not promoted): the branch bottleneck said the finite linear-algebra part "is checked" on the six Pauli eigenstates. Main's wording was kept, updated to say the target is checked only in the narrowed form.

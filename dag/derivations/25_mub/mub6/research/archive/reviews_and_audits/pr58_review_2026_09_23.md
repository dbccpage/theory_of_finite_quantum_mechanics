## Repairs

- **Host transitions and exact inputs.** `symbol_game_host.py` now uses complete
  spanning forests from `l1_governor.compute_phi1`, validates problem edges and
  claims, freezes the supplied problem data, and refuses undeclared dual edges.
  Both hosts check a retraction's proposed output digest before committing it,
  retain prior events, append a restoration event, and advance the state counter
  only on admission. Python verification events include a restoration snapshot.
  Rust problem digests use structured serialization to distinguish names containing
  delimiters; its rationale carrier and dual-section dimensions are checked.
- **Rational witness boundaries.** Q1 LDL input rejects approximate and Boolean
  values. Python and Rust dual witnesses check dimensions, mode counts, vector
  lengths, and nonnegative weights before reconstruction or trace evaluation.
  Malformed Rust witnesses return errors. The former floating-point research pilot
  now invokes the exact two-candidate implementation.
- **Declared interval arithmetic.** B1 receipt auditing rejects nonpositive radii,
  inflated margins, and unsupported analytic promotion. Rust cover auditing also
  rechecks public ball fields and includes the ball radius in continuation erosion.
  The generated anchors remain synthetic data; the receipt's analytic obstruction,
  boundary integration, and hypothesis-elimination flags are false.
- **Reflection and byte binding.**
  `MUB.KernelReflectionB1Intervals.b1_interval_fixture_accepted` checks the canonical
  250 rational intervals and declared margin arithmetic definitionally `by rfl`.
  `test_b1_receipt_matches_reflected_interval_fixture` compares persisted coordinates
  with the reflected data and binds the receipt's canonical LF SHA-256:
  `e747e53283a73c4ce18485631fd4d5f36e0cdc4269006f53ee9458dee7aff05f`.
  This is a finite data/arithmetic check, with no matrix-residual soundness bridge.
- **Visible mathematical premises.** `TargetA10.PointInGlobalDomain` contains only
  geometric membership. `checkGlobalUnifiedCover_sound` additionally requires
  `TreeLeavesObstruction`. APIs that already take obstruction evidence now explicitly
  use `CertifiedPointInGlobalDomain` and `checkGlobalUnifiedCover_certified_sound`.
- **Claim records.** Case-ledger checks reject duplicate/missing branch identities
  and report metadata plus fixed identity samples. The roadmap and classification
  manifest no longer treat the new constructors as a complete named-family
  classification. The Q1 `(1, Pi_i)` fixture is not a full order-2 Lasserre hierarchy.

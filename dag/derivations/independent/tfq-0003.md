# TFQ-0003, finite obstruction signature on two complexes

AuthorityEffect: None.

The shelf statement asks for a finite carrier, a declared comparison, a quotient, and the obstruction signature (Phi1, Gamma2, and the classical residual), with one statement in Python, Rust, and Lean 4, derived from Genesis. This note proves only the finite signature on two complexes. It does not derive that signature from Genesis, and it does not supply Rust.

## Carrier and comparison

The first carrier is the vertex set {0, 1, 2}. The declared comparison is the inequality 0 ≠ 2. That inequality does not build a quotient of edge cochains. The cochain that is 1 on the edge (0, 2) and 0 on the other two edges has face charge -1, so it is not a coboundary.

## Triangle

Oriented edges are (0, 1), (1, 2), and (0, 2). For a vertex function f,

d0(f) = (f(1) - f(0), f(2) - f(1), f(2) - f(0)).

For an edge cochain w = (w01, w12, w02),

d1(w) = w01 + w12 - w02.

A direct expansion gives d1(d0(f)) = 0 for every integer f.

Two edge cochains are equivalent when their difference is d0(f) for some f. Because d1 vanishes on coboundaries, equivalent cochains have the same d1. Conversely, if d1(w) = d1(w'), the difference is a coboundary: the vertex function that is 0 at 0, w01 at 1, and w01 + w12 at 2 clears the first two edges and leaves -(d1(w)) on (0, 2). When d1(w) = 0 that remainder is 0. So the quotient of edge cochains by coboundaries is classified by the integer d1(w).

The quotient residual mass Phi1(w) is the minimum, over vertex functions f, of the L1 norm of w - d0(f). The same clearing repair attains the value |d1(w)|. It is a minimum because

|x| + |y| + |z| ≥ |x + y - z|

and x + y - z equals d1(w - d0(f)) = d1(w). The closure charge Gamma2(w) is |d1(w)|. Thus Gamma2(w) = Phi1(w) on this complex.

The classical residual is the ratio Gamma2 / Phi1 when Phi1 ≠ 0, the value 0 when both vanish, and a refusal when Phi1 = 0 and Gamma2 ≠ 0. On this complex the refusal cell is empty, because the two charges are equal.

For w = (1, 1, 0), d1(w) = 2, so Phi1 = 2 and Gamma2 = 2. The ratio is 2/2 = 1. The repair f = (0, 1, 0) leaves the residual (0, 2, 0), whose L1 norm is 2. The zero cochain has Phi1 = 0, Gamma2 = 0, and classical residual 0.

## Unfilled 4-cycle

Vertices are {0, 1, 2, 3} and edges are (0, 1), (1, 2), (2, 3), (3, 0). No 2-cell is declared, so Gamma2 is defined to be 0. The holonomy is the sum of the four edge values. Every coboundary has holonomy 0, and the L1 distance to the coboundaries is the absolute holonomy. For w = (1, 0, 0, 0) that distance is 1, so Phi1 = 1, Gamma2 = 0, and the classical residual is 0. The class is not exact. This separates a closed nonzero residual from the exact zero class of the triangle.

## What is proved

On the triangle, d1 ∘ d0 = 0, the quotient is the integer d1, Phi1(w) = Gamma2(w) = |d1(w)|, the sample (1, 1, 0) has Phi1 = 2, Gamma2 = 2, and classical residual 1, and the zero cochain has both charges 0. The comparison 0 ≠ 2 does not make (0, 0, 1) exact. On the unfilled 4-cycle, w = (1, 0, 0, 0) has Phi1 = 1, Gamma2 = 0, and classical residual 0, and is not a coboundary.

## What is assumed

Integer arithmetic, the two complexes as declared data, and the reading that Gamma2 on a complex with no 2-cell is 0. No continuum, no measure, and no Genesis event is used.

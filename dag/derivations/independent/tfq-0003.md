# TFQ-0003, one 3-cycle obstruction signature

AuthorityEffect: None.

## Carrier

The carrier is the set of integer triples `(z0, z1, z2)`. The entry `zi` is the value on the oriented edge from vertex `i` to vertex `i+1` modulo 3. Comparison is equality of these integers. A vertex cochain is another integer triple `h = (h0, h1, h2)`.

## Coboundary and holonomy

The coboundary is

`d0(h) = (h1 - h0, h2 - h1, h0 - h2)`.

The holonomy is the sum of the three entries. The sum of `d0(h)` is zero, because the positive and negative appearances of each `hi` cancel. Subtracting a coboundary therefore does not change the holonomy: `hol(c - d0(h)) = hol(c)`.

In this note `Gamma2` means that holonomy. It is unchanged by the coboundary gauge. It is not a sum of squares.

## Quotient

If `hol(c) = 0`, the vertex cochain `h = (0, z0, z0 + z1)` has `d0(h) = c`. The third component is `0 - (z0 + z1) = z2` precisely because `z0 + z1 + z2 = 0`. So the coboundaries are exactly the holonomy-zero triples.

If two triples have the same holonomy, their difference has holonomy zero, hence is a coboundary, hence they lie in the same coset. The converse is the gauge identity above. The quotient of 1-cochains by `im d0` is therefore classified by the integer holonomy.

## Phi1 and the classical residual

The unweighted L1 norm is `|z0| + |z1| + |z2|`. The triangle inequality gives `|hol(c)| <= l1(c)`. Every triple in the class of `c` has the same holonomy, so `|hol(c)|` is a lower bound on the class. The triple `(hol(c), 0, 0)` has that holonomy and L1 norm `|hol(c)|`, so the bound is attained. The triple `(0, hol(c), 0)` attains it as well. If `hol(c)` is not zero, the first entries `hol(c)` and `0` differ, so these two minimizers are distinct. The pair `(Phi1, Gamma2)`, with both read from the holonomy, does not select a unique classical residual on this complex.

For `(1, -2, 4)` the holonomy is `1 + (-2) + 4 = 3`, so `Phi1 = 3`, while the raw L1 norm is `1 + 2 + 4 = 7`. The raw triple is not a minimizer. Its classical residual is `(3, 0, 0)`, which is a different triple.

## What is proved

On this one unweighted 3-cycle, the holonomy classifies the coboundary cosets, `Phi1` equals the absolute holonomy and is attained by two explicit residuals, those residuals differ when the holonomy is nonzero, and the sample values are 3 and 7.

## What is assumed

Integer arithmetic, the declared 3-cycle coboundary, the unweighted L1 norm, and the reading of `Gamma2` as the holonomy. No external analysis, no continuum, and no choice of weights.

## What is open

The shelf sentence that the F000 volume is not by itself a completed pass from Genesis into the obstruction calculus is not a theorem here. Weighted masses, every complex other than this 3-cycle, and every other reading of `Gamma2` remain open.

# TFQ-0319, a finite unjoined receipt

The node asks for a certified term map from the sealed-derivation-v1 receipt into the PrimitiveDifference carrier, or for the receipt and the carrier to stay unjoined. This note records one finite case of the second reading. It does not supply the certified map.

## Data

The receipt in this case has seven nibbles and one green bit. The nibbles are 3, 1, 0, 0, 12, 4, 14. Reading them in base 16 gives the prefix 3100c4e named in the node statement. The green bit is true. These eight fields are a record. They are not a function on a carrier.

The carrier in this case is the set of functions from a two-mark set to the additive group of integers modulo 2. There are four such functions. Written as the ordered pair of values at mark 0 and mark 1, they are (0, 0), (0, 1), (1, 0) and (1, 1).

The coboundary of a function f on an ordered pair of marks (u, v) is f(v) - f(u), with the difference taken modulo 2.

## Carrier arithmetic

For each of the four functions and each mark u, f(u) - f(u) = 0. So every self-coboundary in this list is 0.

On the ordered pair (0, 1) the four coboundaries are:

- (0, 0) gives 0 - 0 = 0
- (0, 1) gives 1 - 0 = 1
- (1, 0) gives 0 - 1 = 1, because -1 is congruent to 1 modulo 2
- (1, 1) gives 1 - 1 = 0

The four value pairs are pairwise distinct, and every ordered pair of marks-values in {0, 1} × {0, 1} appears once.

## Pairing

Form four pairings by attaching the same receipt to the map indices 0, 1, 2 and 3. Each pairing stores the sealed receipt, so each green bit is true, and the four receipts are equal. The map-index fields are 0, 1, 2 and 3, so the four pairings are pairwise distinct: there are six unordered pairs of indices, and each pair differs.

Pairing 0 and pairing 1 therefore carry one receipt and two indices. The edge coboundary attached to index 0 is 0. The edge coboundary attached to index 1 is 1. Those values differ. A true green bit on this receipt does not select the edge coboundary.

## What is proved

On this two-mark carrier, the four listed functions have self-coboundary 0, and their coboundaries on (0, 1) are 0, 1, 1 and 0. The seven nibbles 3, 1, 0, 0, 12, 4, 14 are the base-16 digits of 3100c4e. The four pairings of that one green receipt with the four map indices are pairwise distinct, and two of them carry different edge coboundaries.

## What is assumed

Arithmetic is the ring of integers modulo 2, and equality of finite records is fieldwise. The seven nibbles are the prefix written in the node statement, stored as data. No identification of that prefix with a git object is used. AuthorityEffect is None.

# TFQ-0374, three contracts on one new letter

The node asks for one finite witness, on one new letter, where language restriction, partial word recovery, and total erasure disagree, and for that witness to stay apart from free-monoid size. This note records that witness. It does not open the atlas files named by the node.

## Letters and the witness word

There are two letters. Call them a and fresh. The letter a is old. The letter fresh is the new letter, and fresh is not a. Every letter in this file is one of those two.

The old word is the one-letter word [a]. The witness word is [a, fresh]. It contains the new letter once.

## The three contracts

A word is old when every letter in it is a.

Language restriction takes a list of words and keeps the old words. Its result is a list of words. On the sample list [[a, fresh], [a]] it returns [[a]]. The witness word is not in that result. The old word is.

Partial recovery takes a word and returns that word when it is old. Otherwise it returns no word. On [a] it returns the word [a]. On [a, fresh] it returns no word.

Total erasure takes a word and deletes every letter that is not a. It always returns a word. On [a] it returns [a]. On [a, fresh] it returns [a].

## How they disagree

On the witness word the three results are [[a]], no word, and [a]. Recovery does not return the erased word, because it returns no word while erasure returns [a]. Erasure does not return the witness word. Restriction drops the witness word and keeps the old word.

The three results sit in three different types in the Lean file: a list of words, an optional word, and a word.

## What is proved

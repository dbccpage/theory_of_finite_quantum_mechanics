# TFQ-0385, a uniform rule erases one separation

The node asks for the two-data history in ledger row WDP-P000-017 to stay visible as a counterexample: one unary instance on the first datum separates the two data, and admitting the uniform rule on that form erases the separation. This note records that history. It does not restate the no-return count.

## The history

There are two data, indexed 0 and 1. There is one unary form, index 0. The only context is the hole in that form. Plugging a datum fills the hole with that datum.

Before the rule, the only admitted instance is the plugging of datum 0. A plugging is derivable when the form carries the uniform rule, or when the plugging is that instance. So datum 0 is derivable and datum 1 is not. The two profile bits differ. The class count is 2.

AdmitRuleAll on form 0 turns the rule bit on and leaves the instance bit on. Every plugging of form 0 is then derivable. Both profile bits are true. The class count is 1.

The profile bit of datum 0 is unchanged. The profile bit of datum 1 changes from false to true. The class count changes from 2 to 1.

## What is proved

On this two-datum unary carrier, the instance-only state has class count 2, and the same instance plus the uniform rule on form 0 has class count 1.

## What is assumed

Derivability is the disjunction above. Profiles are the two bits of that one hole-context. Equality of bits is Boolean equality. AuthorityEffect is None.

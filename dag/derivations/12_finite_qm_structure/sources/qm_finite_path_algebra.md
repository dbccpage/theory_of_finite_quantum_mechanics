## FP1: the faithful path representation

Let Q be a nonempty finite acyclic directed multigraph, with parallel edges
retained as different generators. Let P be its **complete** set of directed
paths, including one identity at each vertex. Write pq for p after q, and put
A = C[Path(Q)], with noncomposable products zero. This explicitly supplies a
complex linearization; it is not inferred from a native event alphabet.

On H = C^P with the declared orthonormal path basis, define
L_p δ_q = δ_(pq) when composable, and zero otherwise. Associativity of
concatenation gives L_p L_q = L_(pq), including zero products, and the sum of
object identities acts as I. For ξ = sum_x δ_(id_x),
L(sum_p a_p p)ξ = sum_p a_p δ_p. Thus L is a faithful algebra representation.
More specifically, a_p is the entry in row p and column id_(source(p)).

The implementation refuses cycles or an exceeded complete-path budget. A
truncated enumeration cannot be substituted for P: that can lose composition
closure and invalidates the proof.

## FP2: exact generated star algebra

Let H_x span the paths starting at x and N_x = dim H_x. Every L_p and L_p*
preserves each H_x. Therefore the matrix star algebra D generated by L(A)
satisfies D ⊆ direct_sum_x End(H_x).

For an edge e, L_e is a partial isometry whose range consists exactly of the
paths with last edge e. Every nonidentity path ending at x has a unique last
edge ending at x. Those ranges are disjoint, and L_(id_x) is the projection
onto all paths ending at x. Consequently

```text
P_x = L_(id_x) - sum_(edges e ending at x) L_e L_e*
    = |id_x><id_x|.
```

For any p,q starting at x, direct evaluation on the path basis gives
L_p P_x L_q* = |p><q|. Hence D contains every matrix unit in every origin
block, proving

```text
D = direct_sum_x M_(N_x)(C),       dim_C D = sum_x N_x^2.
```

This constructive proof needs no classification theorem. Finite dimensionality
also makes D closed in the usual matrix norm. Matrix adjoints are **added**
operations; a reverse-history event has not been constructed. In particular,
the adjoint of a nonidentity edge need not belong to L(A).

The ordinary matrix trace supplies τ(T*T) = sum_(i,j) |T_ij|^2, strictly
positive for nonzero T. Distinct L_p have disjoint matrix supports by free-path
cancellation. If d_x counts paths ending at x, this also gives
τ(L(a)*L(a)) = sum_p d_(source(p)) |a_p|^2. The identity path ensures d_x ≥ 1.
This is a positive form for supplied matrices and scalars; it does not select
a physical state cone, an effect set, a Born readout, or a composition rule.

## FP3: selecting one origin changes the faithfulness question

The block projection D → End(H_x) is surjective. Its restriction to L(A) is
faithful exactly when x reaches every vertex. Indeed, L_p has nonzero
restriction exactly when a path from x to source(p) exists, and the nonzero
restricted L_p still have disjoint supports. If y is unreachable, L_(id_y)
is killed. By contrast, this block projection is faithful on all of D only
when Q has one vertex: every other origin has a nonzero identity-path vector
and hence a nonzero central projection that the map kills.

The exact example has two parallel edges 0→1, one edge 1→2, and one edge 0→2.
It has nine paths and origin counts (6,2,1), so D = M6(C) ⊕ M2(C) ⊕ C,
of dimension 41. Restricting the nine-dimensional path algebra to origins
0,1,2 has respective ranks 9,3,1. Thus choosing the six-dimensional block
retains path-algebra faithfulness but loses two sectors of the star completion.

For the central projection Z_1 onto H_1, restriction to H_0 gives zero, while
τ(Z_1*Z_1) = 2. If that quadratic question is protected, any decoder of the
same report for 0 and Z_1 has worst error at least 1, with the midpoint
attaining that two-input bound. This is the WDP report-fiber argument for a
declared question. It does not declare every algebra element an available
physical preparation. On density states, block selection can decrease trace;
normalization requires conditioning and an availability premise.

## FP4: path phases and the endpoint distinction

Given unit edge phases χ_e, let χ_p be their product along p, and let
U δ_p = χ_p δ_p, with identity-path phase one. Then U is unitary and
U L_e U* = χ_e L_e. This uses a separate phase for every path. It does not
establish an endpoint potential. In the example, assigning opposite signs
to the parallel 0→1 edges precludes a single endpoint ratio, while the path
diagonal unitary still exists. The tests check this exact sign control.
The endpoint-descent and FSP holonomy obligations in the
[groupoid note](qm_finite_history_groupoid.md) therefore remain distinct.

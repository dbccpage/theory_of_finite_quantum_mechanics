# Where the project stands

This page is generated by `scripts/build_status.py` from the derivation DAG, the campaign log and the git history. It reports; it does not argue. Daily digests are in [the digest index](daily/index.md).

## How to read the numbers

- A status label is only as strong as its evidence. `PROVED_LEAN` means a named Lean declaration exists in the checkout and the source cites it. It does not mean that every node with that label was re-elaborated for this page, and a node count is not a count of theorems.
- `COMPUTATIONALLY_CHECKED` means an exact finite computation exists. It is not a proof of a general statement.
- `CONDITIONAL` and `IMPORTED_ASSUMPTION` nodes depend on structure that is supplied, not derived.
- Labels have been lowered in the past when review found them too strong. The record of those cases is in the [`README.md`](https://github.com/dbccpage/theory_of_finite_quantum_mechanics/blob/main/README.md) section “How claims are kept honest”.
- The per-node evidence pages are being built; see [the evidence map (in progress)](../evidence/README.md).

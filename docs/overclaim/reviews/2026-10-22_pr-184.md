## Corrections to the PR's own text

- Outcome class and title: the PR says **Reduced** and "Local channel Schmidt rank preservation in finite dimension". The campaign README defines Reduced as "the statement is proved from a strictly weaker, explicitly named assumption" and the node then becomes CONDITIONAL. The node's statement (a mediated-entanglement inference with a mediating system M, locality, a classical-medium definition) is not proved from anything here, and the node correctly stays IMPORTED_ASSUMPTION. The honest class is **Narrowed**: a finite special case is proved. Reclassified in the LOG, the note, the receipt and the independent check.
- "local channel", "finite dimension": the Lean as submitted covers only `Mat2` (two qubits over Q(i)) and a single pair of linear maps `A (x) B` on a pure state. It does not define a channel (no completely positive map, no ancilla, no mixed state, no mixture, no classical communication). Corrected: the review adds `schmidtRank_local_le` (any field, any finite index types) so that "does not raise Schmidt rank" is now stated in general finite dimension, for one linear local map on one pure state; "channel" claims are removed.
- `ClassicalMediatorBranch` (Lean line 45) is, by definition, a pair of local operators `(A, B)`. It models no mediating system and no classical medium; the theorem `classical_mediator_cannot_produce_entangled_state` is `no_local_op_produces_entangled_state` under another name. Docstring corrected; the note says so.
- `LoccMediatorModel` (line 191) takes `preserves_zero_det` as a **field**, so `reduction_of_mediated_entanglement_inference` restates its hypothesis (rubric failure classes 4 and 5). It is not evidence that LOCC or any mediator preserves the determinant. Docstrings and the note corrected; the PR-body row that called it FULL "abstract reduction" is marked NOT A THEOREM ABOUT LOCC.
- Header of the Lean module (steps 3 and 5 of its docstring) said LOCC "cannot raise a separable state" and "Any physical medium generating this entanglement ... cannot be modeled by local operations / classical communication". Not stated by any declaration. Rewritten.
- Note section 2.2 item 3 ("in any channel mediated by a classical medium (LOCC), each conditioning measurement branch acts ... every pure branch output remains a product state") covers pure branches only; LOCC outputs are mixtures, and entanglement of a mixed state is separability, not Schmidt rank. Rewritten under "What is open".
- Node `target`, `connections` and `bottleneck` in `dag/fragments/frontier_branches.json` (and so in `derivation_dag.json`, the derivation record and the PFP prompt) said "Reduced ... Schmidt rank preservation in finite dimension". Rewritten to the finite shadow, with an explicit "Not stated" list.
- PR body: corrected through `gh pr edit` (title, outcome class, table).
- The note called the node "Rank 7" and the PR "Target 3": rank 7 is correct (recomputed from `derivation_queue.json`); "Target 3" is not a queue concept. Rank 6 (`PGW-PRESENTATION-NOT-EXPRESSIVE-LIFT`) is neither attempted nor listed in `skipped.md`; the campaign README says to take targets in rank order. Process note only, not corrected here.

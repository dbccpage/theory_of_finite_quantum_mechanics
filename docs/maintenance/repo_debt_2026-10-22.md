## Sub-task 3: `lean4/CausalOrder.lean::incomparability_not_transitive_c1`

### 3.1 Defect Analysis

In `lean4/CausalOrder.lean`, the theorem previously named `incomparability_not_transitive_c1` had the signature:

```lean
theorem incomparability_not_transitive_c1 :
    isSpacelike c1_rel C2.e0 C2.e1 ∧
    isSpacelike c1_rel C2.e1 C2.e0 ∧
    ¬ isSpacelike c1_rel C2.e0 C2.e0
```

Because `x = C2.e0`, `y = C2.e1`, and `z = C2.e0` only use two distinct elements (`z = x`), the conjunction `isSpacelike r x y ∧ isSpacelike r y x ∧ ¬ isSpacelike r x x` holds for any symmetric, irreflexive relation `r` that holds on at least one pair `(x, y)` — including relations that are transitive on all triples of pairwise-distinct elements.

### 3.2 Fix Applied in `lean4/CausalOrder.lean`

1. **Honest naming + backward-compatible deprecated alias**:
   - Renamed the two-element `C2` lemma to `c1_spacelike_symm_irrefl`.
   - Retained `@[deprecated c1_spacelike_symm_irrefl (since := "2026-10-22")] theorem incomparability_not_transitive_c1` so any external callers continue to type-check with a deprecation notice.
2. **Genuine non-transitivity on three distinct elements (`N4`)**:
   - Defined the 4-element N-poset `N4` (`e0`, `e1`, `e2`, `e3`) with strict order `n4_rel`: `e0 < e2`, `e1 < e2`, `e1 < e3`, and proved `n4_strictPoset : IsStrictPoset n4_rel`.
   - Proved `n4_spacelike_not_transitive`:
     ```lean
     theorem n4_spacelike_not_transitive :
         N4.e0 ≠ N4.e3 ∧ N4.e3 ≠ N4.e2 ∧ N4.e0 ≠ N4.e2 ∧
         isSpacelike n4_rel N4.e0 N4.e3 ∧
         isSpacelike n4_rel N4.e3 N4.e2 ∧
         ¬ isSpacelike n4_rel N4.e0 N4.e2
     ```
     Specifically, `e0` and `e3` are spacelike (`¬ e0 < e3` and `¬ e3 < e0`), `e3` and `e2` are spacelike (`¬ e3 < e2` and `¬ e2 < e3`), yet `e0 < e2`, so `¬ isSpacelike n4_rel N4.e0 N4.e2` across three pairwise-distinct elements `e0`, `e3`, `e2`.
   - Proved the existential packaging theorem `spacelike_not_transitive`:
     ```lean

         ∃ (r : N4 → N4 → Prop), IsStrictPoset r ∧
           ∃ x y z : N4, x ≠ y ∧ y ≠ z ∧ x ≠ z ∧
             isSpacelike r x y ∧ isSpacelike r y z ∧ ¬ isSpacelike r x z
     ```

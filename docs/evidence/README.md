# Evidence map of the derivation DAG

AuthorityEffect: None. This directory is generated by [`dag/evidence/build_evidence.py`](../../dag/evidence/build_evidence.py) from [`dag/derivation_dag.json`](../../dag/derivation_dag.json) and the files in this checkout. It changes no status and adds no result. Its job is to show, node by node, which files back each claim, how strong that backing is, and where a status says more than the backing supports.

The machine-readable form is [`dag/evidence/evidence_map.json`](../../dag/evidence/evidence_map.json). Each node has a page under [`nodes/`](nodes) and each stage a table under [`stages/`](stages). Everything below is recomputed by `python -I -X utf8 dag/evidence/build_evidence.py --check`.

## Progress at a glance

- Lean receipts are the files in `dag/research/` whose Lean results carry a module name and a sha256. A receipt covers a Lean file, not a single declaration, unless the receipt itemises the declaration's axioms. 1332 of the 1377 receipt-backed declarations are itemised; the others rest on the module-level audit. A cited symbol is matched to a receipt name only if the receipt name equals it or ends in a dot followed by it; when more than one receipt name matches, the match is recorded as ambiguous and no axiom list is copied (0 declarations).

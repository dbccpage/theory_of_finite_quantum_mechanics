## Statement

> l1_regge.py is a NumPy and SciPy float script. It estimates valency deficits with machine pi, calls a float linear program on areas, and stores radian deficits from an inverse cosine. Those floats are not an exact rational Regge calculus, and they are not the Einstein-Hilbert action. A printed deficit on a handful of hinges does not equal curvature of a smooth manifold; that identification stays GAP. What is finite is a short list of integer valencies in floating arithmetic. What is not discharged is a continuum limit, the Einstein equation, and any quantum-gravity reading of the returned dictionary.

The proved fragment is the triangle and the unfilled 4-cycle below. Checked slice (Lean 4 and an independent Python check), two finite complexes only, with no status change: On vertices {0,1,2} the declared comparison 0 != 2 does not make the edge cochain (0,0,1) a coboundary. The coboundary is d0(f) = (f(1)-f(0), f(2)-f(1), f(2)-f(0)) and the face charge is d1(w) = w(0,1)+w(1,2)-w(0,2), and d1 composed with d0 is 0. Quotient residual mass Phi1(w) equals the absolute value of d1(w) and is attained by clearing the first two edges; closure charge Gamma2(w) equals that same value. For w = (1,1,0), Phi1 = 2 and Gamma2 = 2, so the classical residual is 2/2 = 1, also attained at the repair (0,1,0) whose residual is (0,2,0). The zero cochain has Phi1 = 0, Gamma2 = 0, and the both-vanish value 0. On the unfilled 4-cycle with edges (0,1), (1,2), (2,3), (3,0) there is no 2-cell, Gamma2 is 0, and Phi1 equals the absolute edge sum; w = (1,0,0,0) has Phi1 = 1, Gamma2 = 0, classical residual 0, and is not a coboundary. The rule that refuses the ratio when Phi1 = 0 and Gamma2 is not 0 is not met on either complex. Rust, a common three-language statement, and a derivation from Genesis regime events are not proved.

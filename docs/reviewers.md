# Reviewers

**AuthorityEffect:** None.

This table records independent reviews of nodes, proofs, derivation notes and tools, with credit to the reviewers. A row is added by the maintainer after a *Derivation review* issue is opened and read; see [`REVIEWING.md`](https://github.com/dbccpage/theory_of_finite_quantum_mechanics/blob/main/REVIEWING.md) for the process and the verdict scale (A agree, B agree with remarks, C disagree, N not assessed).

A row records one reader's opinion on stated files at a stated commit. It is not a certification of a node, and a favourable row does not change a node's status. Reviewers choose the name and affiliation shown, or none.

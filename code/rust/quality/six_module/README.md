# Six-module L4A review

AuthorityEffect: None.

The goal covers every Rust file recursively in `combinatorics`,
`category_theory`, `finite_probability`, `fusion_categories`,
`general_relativity` and `higher_category_theory`. The repeated combinatorics
path is counted once. The initial inventory had 318 Rust sources;
`progress.json` records the current set as main adds modules and examples.
The six-directory scope stays intact.

Every source has `<name>.rs.scoring.yaml` and `<name>.rs.contract.yaml`.
These JSON documents are valid YAML 1.2. Independently authored existing PFP
contracts are preserved. Earlier category `.score.yaml` records remain intact.

The architecture target is L4 and engineering target is A. Delivered capability
levels remain honest: a small alias does not become L4 by receiving a sidecar,
and existing L5 architecture is retained. A declared target is not an attained
score. The ledger retains the established category assessments and individually
authored combinatorics reviews. Current completed/incomplete counts are explicit
in `progress.json`. Draft contracts have null
specifications and named open obligations, rather than invented guarantees.
Contract definitions are projected from actual source reviews where available;
they are not extracted Rust proofs or new grade awards.

Run `py -3.10 code/rust/quality/six_module/sync_companions.py --check` to check
all companions, rubric/source digests, existing assessment references, immutable
score manifests and measured structural ceilings. Updating companions uses the
same command without `--check`; it does not perform a missing semantic review.
This command requires PyYAML, available in the existing Python 3.10 environment.

`run_enumeration.py` uses the actual standalone combinatorics crate and copies
the selected `--subject enumeration`, `cartesian_words`, `partitions` or
`color_constraints`, `finite_geometry`, `weyl_systems` or
`mub_configurations`, `lib` or `mod` into one-fault
namespaces, keeping its real sibling providers.
It preserves all six mutation outcomes and separates compiler refusal from test
failure. The exact independent oracle is in `enumeration_challenges.rs`. The
canonical 44 tests and the unmodified enumeration subject's nine tests pass; all 20
designated enumeration faults are killed. Before-repair receipts retain two reachable
capacity-overflow panics. The repaired public boundary admits widths before
allocation and bounds eager weak-composition cells, using iterative traversal
instead of recursion. Public admission is intentionally narrowed; no blanket
compatibility for formerly unbounded requests is asserted. The complete 18-body
review is now L4A, supported by 19 clean Lean arithmetic/refusal declarations.
Cartesian words also receives L4A: all four production bodies, six copied-subject
tests, an independent 26,220-word positional oracle and 14 detected faults are
bound to its exact source. Eleven clean model declarations prove positional range,
injectivity, exact carry and maximal exhaustion; Rust reverse-vector and ownership
correspondence remains a distinct source review. Taking the private current vector
removes an unnecessary full-word clone per output.

Partition APIs now have L4A reviews across all five production bodies. Borrowed
DP summands avoid repeated BigUint clones, explicit DFS frames replace recursive
traversal, and eager output admits a conservative count-times-n cell bound.
Conjugacy arithmetic admits the total before map/power work and checks exponent
conversion. Independent pentagonal counts cover n=0..1000, cut masks give exact
small lists, and cycle histograms cover all 46,234 permutations through S8.
All 21 faults are detected. Fifteen clean model declarations include actual
Mathlib partition and symmetric-group cardinality/divisibility statements;
complete DP/stack and fixed-point correspondence remain explicit source arguments.

Color search also has L4A across eight production bodies, with reusable violation
buffers and unchanged first-minimum semantics. A complete independent argmin
oracle checks 6,982 small instances plus duplicate/oriented-edge, typed-priority
and resource cases. All 18 final faults are detected, with thirteen clean model
declarations for global argmin, membership, stable ties and zero early exit.
The initial minimum-direction fault timed out on a usize::MAX-palette search.
That receipt remains inconclusive; final fault searches are bounded while the
original successful huge-palette control and maximum admission checks are retained.
Both earlier completed reviews have fresh package/provider/caller replays.

Finite geometry also receives L4A: all 22 production bodies, 23 detected final
faults, and thirteen clean kernel-checked declarations for actual affine field
lines, the concrete Fano table, integer dot symmetry and admission/index facts.
Unequal vector widths now refuse before arithmetic; square/input/work budgets
are checked before output allocation. Zero vectors and zero width remain
intentional integer-vector cases. Independent bitmask incidence, XOR Fano,
modular line equations and i128 dot oracles support the source correspondence.
Before-repair failure, a surviving initial shape mutant and the rejected first

Weyl systems and MUB configurations also receive L4A with all 27 production
bodies mapped, 19 and 14 detected final faults respectively, and fifteen clean
shared model declarations for alternating forms, unique prime-field directions,

Operator-bundle completeness is not an eigenbasis or composite-dimension theorem.
The pre-repair failures, initial surviving size mutant and rejected proof remain

All nine combinatorics files now have complete engineering-A assessments. The

Fusion review includes exact boundary repairs and two complete L1A aggregate

The bounded ring now receives L4A with all 74 production bodies individually
contracted, 29/29 detected final critical source faults, explicit whole-file
invariant/cost/consumer review, and fourteen clean matrix/counting/work-admission
model declarations plus the earlier rank/ratio model. The first matrix-model
draft was rejected for an unintended pointwise-product interpretation and remains

Group operations stream mixed-radix coordinates without digit-vector allocation.
Path counting admits conservative scalar-bit work before BigUint arithmetic,
reuses two buffers, skips zero terms and moves target counts. Direct flat matrix
construction and exact-capacity table flattening remove avoidable intermediates.
Unexpected fractional spectral coefficients refuse before conversion. The
spectral FP interpretation is a separate cited finite-matrix source argument;
its provider budgets can refuse. Lawful generic scalar implementations remain
an explicit domain/TCB assumption. Ring admission certifies a based ring, not a
fusion category, braiding, statistics or categorical realizability.

`reviewed_assessments.py` checks their actual native/dependency/proof/metric
receipts with the existing weakest-link and proof verifiers. It checks each
compiled mutant against its exact source substitution and frozen fixture, and
each mapped production signature/body against source. The writer cannot create
a gate review from test counts. Thirteen decoded-value probes challenge accounting,
kill attribution, structural ceilings and complete/accurate body mapping without
editing any source or immutable receipt. Legacy grades keep their immutable
score-manifest custody. Failed proof and interrupted receipt attempts remain
retained without primary grading credit.

above at least one A ceiling; the expanded 320-source run finds 192. Each file
records its own measurements. Opaque
macros, runtime costs and caller review remain distinct from metric ceilings.

# PO-000 `24 g^2` chain: exact Rust coverage

Paper: `projection_obstruction.md` (the_symbol_game,
`F004_papers/002_projection_obstruction/000_projection_obstruction`),
§5.1–§5.4.1, §5.7(1), §5.8 (Lemma 5.4, Theorem 5.5 at `J = 1`), Appendix B.
Claim-ledger rows touched: E2 (Lemma 5.3), E3 (Lemma 5.2), E4 / E4-second /
E4-commutator (Theorem 5.1), E4-general (Theorem 5.5), R2 (§5.4.1).

Code: `po000_24g2.rs` (the chain, its instances and tests) and
`po000_exact.rs` (Gaussian-rational matrices, partial traces,
Faddeev–LeVerrier characteristic polynomials, Yun square-free factorisation,
Sturm root isolation). Every asserted value is an exact `BigRational` or
Gaussian rational, or a rational interval certified by Sturm counting on an
exact characteristic polynomial. No floats are used anywhere.

**Scope.** These are computations on declared finite instances. They do not
establish the general theorem for all finite graphs and all `t`. Where a row
says "all `s`", the instance constant is exact, but the inequality it bounds
(`‖ad_H²(A_S)‖ ≤ c2(S)`) rests on the paper's triangle-inequality argument.
The code spot-checks that inequality against exact double commutators. It does
not prove it.

`D_e(t)` at rational `t` is enclosed in two steps. First the code computes the
exact truncated series `Σ_{k≤K} t^k ρ^(k)(0)/k!` of the full state. It then
adds a tail bound `δ = x^{K+1}/(K+1)!/(1 − x/(K+2)) ≤ 10⁻¹²`, where
`x = t·Σ_X s_X` and `s_X ≥ ‖ad_{h_X}‖`. This tail bound does not use the
paper's lemmas. The truncation error on `F_e` is at most `δ(3+δ)`. Finally the
code takes a Sturm enclosure of `‖F_K(t)‖₁`. The checks use worst-case interval
endpoints. Lower bounds use `ν_hi` and `g_lo`; a certified violation uses
`D_hi < ν_lo t − c g_hi² t²`.

## Counts

- Exact finite / exact arithmetic of a counting rule: 8 rows
  (Lemma 5.2 constants ×2, §5.1 split, `ν` values, the 48 and 24 constants,
  Lemma 5.4 route, refusals).
- Finite instance of a general claim: 10 rows (Lemma 5.2 on instances,
  double-commutator spot check, §5.2 consequences, Lemma 5.3, Appendix B
  instance constant, Thm 5.1, half-slope window, Thm 5.5 `J=1`, `ν=0` case,
  §5.4.1).
- Not computable by finite means: the general statement for every finite
  graph, every local dimension and every `t ≥ 0`. In particular the
  branch inequality `‖ad_H²(A_S)‖ ≤ c2(S)` for all `A_S` and all `s` is a
  proof step, not a computation.
- Counterexamples: 2 certified counterexamples, both to **deliberately wrong
  variants** (fields dropped from `g`, raw rate in place of `ν_e`). None of
  the paper's own claims in this chain failed on any instance.
- Not caught: the wrong constant `23` (nor `2`). 24 is not shown sharp.

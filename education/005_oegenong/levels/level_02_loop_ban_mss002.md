# Level 02: when an identification makes `xrx`

**Package:** [`001_genesis_ongoing_h3v7n5qf`](../../../../omega_engine_atlas/coda_atlas/F004_papers/001_finite_obstruction_calculus/001_genesis_ongoing_h3v7n5qf).

In the base Lean file `lean4/H3V7N5QF/Basic.lean`, `identification_obstructed_iff` says that identifying `u` and `v` in a legal asserting makes some `xrx` asserted exactly when `urv` or `vru` is asserted.

Python `obstruction` in `code/xry/changes.py` names the assertions in the way. On `given(False, Sameness.FREE)`, identifying 0 with 1 returns `((0, 1),)`. On `given(True, Sameness.FREE)` it returns `((0, 1), (1, 0))`. Adding a term returns the empty obstruction.

The sixth derivation drops the ban sentence. The seventeenth derivation strikes the ban and keeps obstruction wording. Those manuscripts are `paper/sixth/paper.md` and `paper/seventeenth/paper.md`. The filename of this page keeps the education label `mss002`. MSS stage numbers are an education crosswalk. They do not appear in the pinned repository.

## Research Working Notes (`research/`)

The working notes contrast intrinsic state illegality with external gate obstruction:

- **Sixth derivation notes (`research/sixth/reading_the_seed.md`):** Striking the loop ban removes the prohibition on `xrx`. As a result, no change can be obstructed: all attempts proceed without refusals or answering branches.
- **Seventeenth derivation notes (`research/seventeenth/reading_the_seed.md`):** Decouples structural legality from operational gating: self-loops `xrx` are admitted into the carrier state representation, but changes that would introduce them remain obstructed by policy.

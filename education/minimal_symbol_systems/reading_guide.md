# Reading the MSS verification atlas

AuthorityEffect: None. The MSS atlas has entries 0–100. An entry is a
specification with a carrier, grammar, evaluator and lift obligations; its
presence does not certify that Genesis derived that stage.

Read [the foundational monograph](/atlas/papers/finite_obstruction_calculus/pregenesis_to_minimal_symbol_systems/paper.md) alongside the
[levels index](levels/README.md). Start with [extension and retraction](levels/level_06_tower_extension_retraction.md)
before using higher entries. The former frontier laboratories (retired 2026-10-06)
explored particular finite examples; a hardcoded status or count in a notebook
does not verify the corresponding implementation.

## Separate the questions at each entry

| Question | Evidence needed |
| --- | --- |
| Is the word syntactically admitted? | The declared grammar and parser result |
| Does the evaluator compute the claimed value? | Actual inputs, implementation and independent replay |
| Is this a lawful lift? | Obstruction, preservation, non-destruction, budget/permission and terminal route |
| Is it a native Genesis stage? | Source provenance for that derivation |
| May it execute an effect? | Recognized permission under the active policy |

The [Genesis guide](../001_genesis/reading_guide.md) explains the source
regimes; the [S(n) guide](../002_s_n/reading_guide.md) explains its seven-stage
native core. Matching index numbers between these estates establish none
of the five claims in the table.

## Retrieval checks

Explain why a parser pass, a zero diagnostic and a valid authorization are
three different results. Then give a novel term on which the down-map must
refuse, and describe the witness needed to admit it lawfully. When a level
uses a non-cochain carrier, identify its own evaluator instead of assigning

A concrete loss test is supplied by the [source-16 admission kernel](/atlas/papers/finite_obstruction_calculus/witnessed_difference_programme/docs/admission_execution_refinement.md).
Two states can have identical r/s assertion tables while one has a leftover
and the other does not. Forgetting the record changes future enabled
admissions. Explain why an evaluator that observes only r/s cannot establish
a lift preserving those future questions, even when its present value agrees.

The [primitive context kernel](/atlas/papers/finite_obstruction_calculus/witnessed_difference_programme/docs/primitive_execution_refinement.md)
gives another preservation test. A well-formed uniform-rule admission can
make two previously unequal profiles equal. Its successful syntax check
therefore does not certify that an earlier separation requirement survived.
Name the protected pair, compute both profiles and test the requirement
after the change. When an arity-bounded minimum search returns no response,
record those bounds instead of declaring the whole atlas entry unachievable.

The [complete raising-key example](/atlas/papers/finite_obstruction_calculus/witnessed_difference_programme/docs/gauge_result_refinement.md)
tests another evaluator boundary. Two three-term states have the same
sorted loop, pair and triangle summaries, but only one has its nonzero
two-way edge touching its nonzero loop. Their complete result keys differ.
Identify the protected incidence question that the summary loses. Then
explain why a complete key still cannot recover raw cost when raising
changes that cost. Choose the report according to the questions a lift
must preserve; successful computation alone does not supply preservation.

The [future-balance counterexample](/atlas/papers/finite_obstruction_calculus/witnessed_difference_programme/docs/marked_result_refinement.md) strengthens the lifting
exercise. Zero assertions on two terms and the result of raising term 0

sum 1 in the raised representative.

A lift protecting this future answer must retain enough raw source data
to distinguish those representatives. A present complete result mark does
not supply that data. Compare this loss with the separate table/filling
minima that forget whether a filled triangle contains the loop vertex;
name the protected question in each case.

## Test continuity of the protected verdict

The [presentation-completion criterion](/atlas/papers/finite_obstruction_calculus/witnessed_difference_programme/docs/cs_q_presentation_completion.md)
has a separate mechanized metric proof. It transports a protected answer only
when the answer is uniformly controlled in the presentation metric. Give the
positive real numbers 2^-n their usual metric and give Boolean verdicts the
discrete metric. Every finite positivity verdict is true; the limiting value
is zero. Taking epsilon less than one disproves the required relative modulus
for the query [x>0] at zero.

A useful evaluator needs a proved margin, a restricted domain or an unresolved
boundary. A numeric completion or a total extension function does not preserve
that verdict automatically and does not authorize a lift. State the grammar,
numeric query, decision boundary and permission rule separately.

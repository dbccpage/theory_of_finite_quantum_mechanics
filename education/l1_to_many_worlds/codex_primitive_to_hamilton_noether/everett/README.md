# Two routes, one exit, and a record

[Print the two sheets](two_sheets.pdf). Read the pictures from left to right. Each strip starts a fresh run of the same two-route experiment. The reverse move in the last strip happens before the particle is tested at the exit.

The second sheet states the preparation, measurement rule, and ideal control assumptions. It gives the probabilities for the dark exit in each run and identifies Everett's interpretation of the two records. The preceding [Hamilton and Noether sheets](../two_sheets_v5.pdf) develop the notation for joining and cancelling moves.

An unread path record suppresses interference at the exit. In an ideal reversible experiment, controlling every record permits a joint test that reveals the coherence again. Loss of contrast in the exit counts alone has several possible causes. [Source notes and prior reviews](../../../../atlas/everett_mw/README.md)

For the original relative-state formulation, see [Hugh Everett III (1957)](https://doi.org/10.1103/RevModPhys.29.454). To regenerate the PDF and picture preview, install the [parent renderer dependencies](../requirements.txt) and run `python render.py` from this folder.

# Three tweets on many-worlds

[Read the three tweets](three_tweets.txt) or [print the two sheets](two_sheets.pdf). Read the pictures from left to right. Each strip starts a fresh run of the same two-route experiment. The reverse move in the last strip happens before anyone reads the exit detector.

The second sheet states the preparation, measurement rule, and ideal control assumptions. It gives the probabilities for the dark exit in each run and identifies Everett's interpretation of the two records. The preceding [Hamilton and Noether sheets](../two_sheets_v5.pdf) develop the notation for joining and cancelling moves.

The source draft gave four follow-up posts with a 500-character allowance. This packet has three standalone posts under 280 characters including their numbering. The draft review also identified two places where the audience needs to know which observation is available. An unread path record suppresses interference at the exit. In an ideal reversible experiment, controlling every record permits a joint test that reveals the coherence again. Loss of contrast in the exit counts alone has several possible causes. [Source notes and prior reviews](../../../../atlas/papers/everett_mw/README.md)

For the original relative-state formulation, see [Hugh Everett III (1957)](https://doi.org/10.1103/RevModPhys.29.454). To regenerate the PDF and picture preview, install the [parent renderer dependencies](../requirements.txt) and run `python render.py` from this folder.

## A worked reading exercise

Start with the three-shear LGGR example. Each edge has determinant one and
deviation at most one half. The closed product is
`[[5/4, 9/8], [1/2, 5/4]]`, whose deviation from identity is `11/8`.
Local green therefore coexists with global red under a cycle threshold `1/10`.
Name the graph, comparison list and thresholds before drawing the conclusion.
Zero residual on an empty list of overlaps establishes no global gluing result.

Next, replace a canonical label by a SQL row. Identify the raw carrier, the
equivalence, the transport back, and the protected queries. Delete the transport
and explain which source-level questions can no longer be answered. This is a
direct test of the proposed language boundary, not evidence that a new SQL
backend or HoTT kernel has already been implemented.

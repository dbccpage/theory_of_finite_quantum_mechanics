# Pedagogical Script Standards: Witnessed Difference Programme (WDP)

AuthorityEffect: None.

## Purpose
The `scripts/` directories contain the exact timing, scene breakdowns, on-screen actions, and voiceover scripts for video lessons in the WDP curriculum.

## Format Requirements
Each script must:
1. Match the filename stem of its companion concept and notebook (e.g. `lesson_700_01_monograph_architecture.md`).
2. Declare `AuthorityEffect: None.`
3. Specify target duration (typically `120s` or `180s`) and format (1080p 60fps / 940x580 dark-mode canvas).
4. Provide a structured scene breakdown table with timestamps, visual cues, voiceover script, and epistemic target tags (`[Declared]`, `[Executed]`, `[Tested]`, `[Pinned]`, `[Open]`).

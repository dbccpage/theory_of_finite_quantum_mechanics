# MSS-N Domain Packages

**AuthorityEffect:** None.

This directory organizes the six exploratory and formal domain carrier packages for the Minimal Symbol System (MSS-N) tower:

1. [`physics/`](physics/): Retained finite geometry, graph diffusion, matrix identities and LP examples; see the physics cleanup for withdrawn claims.
2. [`mathematics/`](mathematics/): Cotransitivity theorems, distinctness lemmas, simplicial complex homology, Smith Normal Form (SNF), and formal Lean 4 kernels.
3. [`computation/`](computation/): Polygraph rewriting, confluent peak joins, Church-Rosser reduction, and computational discrete transition kernels.
4. [`cosmology_astrophysics/`](cosmology_astrophysics/): Finite partial orders, crossing-link counts and boundary-matrix products.
5. [`ansi_sql/`](ansi_sql/): Exact relational algebra queries, topological database cells, schema contracts, and view delta verification.
6. [`llms/`](llms/): Finite token lists, precedence graphs and boundary-matrix examples; no actual LLM evaluation is included.

The scripted domain narratives are teaching examples. They are not transcripts
of the frozen Genesis derivation, independent model evaluations, or proofs of
continuum impossibility. Predicate names and supplied Boolean values establish
no bridge theorem; see the [publication review](../publication_review.md).

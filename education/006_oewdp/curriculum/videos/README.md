# Video Asset Guidelines: Witnessed Difference Programme (WDP) Curriculum

AuthorityEffect: None.

## Technical Specifications
- **Resolution:** 1080p (1920x1080) at 60fps
- **Diagram Canvas:** 940x580 dark-mode SVG/CSS layout
- **Codec:** H.264 / AAC (or WebM / VP9)
- **Voiceover Style:** Concise, mathematically rigorous, zero-hype, measured cadence (120–180 seconds target per module).

## Directory Structure
- Video assets for each track reside in the track's respective `videos/` folder:
  - `700_wdp_overview/videos/`
  - `710_wdp_finite_obstruction/videos/`
  - `720_wdp_levels/videos/`
- Companion video storyboard scripts reside in each track's `scripts/` directory matching the lesson stem (e.g. `lesson_700_01_monograph_architecture.md`).

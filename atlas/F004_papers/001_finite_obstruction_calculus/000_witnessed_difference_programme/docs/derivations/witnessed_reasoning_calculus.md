# Witnessed reasoning from an admitted distinction

Date: 2026-10-16. AuthorityEffect: None.

This is a completed conditional reasoning profile, with explicit residuals below.
It supplies the missing inference step between WDP's admitted distinctions and
claims that can be checked, composed, reused and limited by available information.
The choice of a logic and its interpretation are inputs to the construction.

## Admission and syntax

The presentation `<>` has no interpreter, facts or inference rules by itself.
In the empty theory, no atom is derivable: the everywhere-false interpretation
is a model and soundness excludes every proposed derivation. This is a theorem
about the specified empty theory, not an empirical claim about a displayed glyph.
To proceed, admit a carrier of atoms, a fact predicate and a collection of rules.
At least two compatible choices are possible: admit the atom `a` as a fact, or
admit no facts and no rules. The respective consequences differ. Thus this
construction does not select a unique logic from typography or difference alone.

For the first executable profile, atoms form a finite list A of distinct names.
A context Gamma is a subset of A. A rule is a finite list of premises with one
conclusion, written `(a1,...,ak) => b`; zero premises and duplicate premises are
allowed. T = (A, Gamma, R) is a definite propositional Horn theory. Atom names
are opaque: substituting an empirical label does not supply its truth.

The judgment `T |- a` is generated by two rules:

1. **Fact:** if a is in Gamma, derive a.
2. **Fire:** if `(a1,...,ak) => b` is in R and each ai has a derivation, derive b.

A proof is finite. Identity on assumptions is the fact rule. There are no
object-language variables, quantifiers, negation or probabilistic weights in
this profile. A substitution is a map on atoms, with the premise-preservation
conditions in the substitution theorem below. An unseeded cycle supplies no proof.

## Semantics, soundness and completeness

A valuation v assigns truth values to atoms. It models T when every fact is
true and every rule has a true conclusion whenever all its premises are true.
The Lean formulation permits Prop-valued valuations over any atom type.

**WDP-RSN-01 (soundness).** If `T |- a` and v models T, then v(a).
Proof: induction on the derivation. A fact is true by the first model condition;
at a firing, the induction hypotheses make every premise true and the second
model condition supplies the conclusion. The proof handles arbitrary finite
derivations, rather than just the examples in the executable census.

**WDP-RSN-02 (least-model completeness).** Let D(a) mean `T |- a`.
The fact and firing constructors make D a model. Soundness makes D a subset of
every model. Consequently `T |- a` iff a holds in every model of T. A model v
with not v(a) excludes a derivation. This does not say that a is false in the
actual world; it says that the admitted theory does not entail a. In particular,
if both true-a and false-a worlds satisfy the supplied information, the
empirical answer remains undetermined.

**WDP-RSN-03 (substitution and reuse).** Suppose an atom map f carries every
source fact to a derivable target atom and every source firing to a target
derivation whenever its mapped premises are derivable. Interpret source atom a
as target derivability of f(a). This is a source model, so soundness transfers
every source derivation. Identity and composition follow by choosing the
identity map and composing two such transports. Enlarging facts and rules
preserves derivations. More strongly, adjoining an already derivable atom a
as a fact is conservative: the old derivability predicate models the enlarged
theory, giving the reverse inclusion; weakening gives the forward inclusion.
This is the cut principle used for learned facts. It does not license reusing
an empirical assumption, rejected candidate or proof from a changed theory.

## Checked certificates and finite search

**WDP-RSN-04 (checked trace invariant and termination).** A trace starts empty
and appends either a fact or a rule conclusion whose premises have already
appeared. Induction on trace length gives a derivation for every entry. Composing
with soundness gives truth in every admitted model for every accepted entry.
The abstract trace invariant is proved in Lean.

The Python checker reads earlier step indices, matches each premise in order
against the selected rule, and requires the final atom to equal the separately
supplied goal. It checks the theory digest, including atom names, facts and
ordered rules. SHA-256 is a custody mechanism with its usual collision-resistance
assumption, not a mathematical injectivity theorem. The Rust checker instead
compares the full supplied theory for exact equality. Their encodings differ;
no cross-language wire compatibility is claimed. Both validate carrier indices
before access. A changed task is checked against the current source, not the
source asserted by an untrusted proof.

The finite Python searcher repeatedly inserts a missing fact or enabled rule
conclusion. Each insertion strictly increases a subset of A. There are at most
|A| insertions. If the goal appears it returns a proof. If no insertion is
possible, the inserted set contains the facts and is rule-closed: it is a model
omitting the goal, independently checkable as a countermodel. Completeness
follows from this model and soundness. Cycles, empty-premise rules and repeated
premises require no special semantic exceptions. An empty carrier admits no
well-typed query and is refused by the query interface.

A user budget limits insertions. If it expires while another insertion is
possible, the result is `BudgetExhausted`, with no negative conclusion. A fixed
point reached exactly at the budget is still a checkable countermodel. The
budget does not price scans, hashing, proof checking, physical measurement or
wall-clock work. Edition 2.4.5 proves the concrete Lean checker refinement and
adds kernel replay of foreign certificates in
[the executable refinement](executable_reasoning_refinement.md). Universal
Python/Rust source semantics and searcher refinement remain open.

## Original-task refinement: directed reachability

**WDP-RSN-05 (graph interpretation).** Supply a finite directed graph G and a
start vertex s. Atom v means that a directed path in G runs from s to v. The
only fact is s. Each edge u -> v gives the rule u => v.

The empty path realizes the fact. Appending the edge realizes a firing, so every
derivation decodes to a graph path by induction. Conversely, induction on any
finite graph path gives a derivation of its endpoint. Thus graph reachability
and Horn derivability agree, including cycles and paths of length zero. A closed
set containing s but omitting g is a cut certificate: any proposed s-to-g path
has a first edge leaving that set, contradicting closure.

`decode_path` reconstructs the path from checked parent indices. `check_path`
independently checks original graph edges and endpoints without calling the
Horn searcher or reading its rules. Example: edges 0 -> 1 and 1 -> 2 with start
0 give proof entries 0,1,2 and decoded path (0,1,2). Removing edge 1 -> 2 makes
the old certificate stale; the new theory has countermodel {0,1} for goal 2.
This is an actual source-task adapter, not an empirical model of arbitrary
natural-language claims. The general graph argument is written here; the
Python path decoder is tested separately. Edition 2.4.5 formally proves the
general graph equivalence and transports accepted concrete certificates to the
independent reachability relation in Lean.

## Information and self-reference limits

**WDP-RSN-06 (target-separating report limit).** Let E:W -> R contain *all*
information available at the decision, including accessible memory, observations
and task metadata. Let q:W -> Q be the desired answer. If E(w)=E(w') but
q(w) differs from q(w'), no decoder on R is correct on every admitted world.
Otherwise applying the decoder to the equal reports would make the answers
equal. Every deterministic post-processing of E preserves the collision.
This proves revised CH14-T01 and CH14-C01. Noninjectivity of E alone is
insufficient: every constant question has a constant decoder even through a
constant report. An internally supplied graph can still be reasoned about exactly.

**WDP-RSN-07 (interactive limit).** For a deterministic total transition system,
define s ~ t when observations agree after every finite word of admitted actions,
including the empty word. If q(s) differs from q(t), even the full function from
action words to reports cannot determine q. Apply WDP-RSN-06 to that function.
Any finite deterministic observation-based policy sees the same successive
reports and chooses the same actions, by induction. A decision functional of
the complete report tree also has identical input. An instantaneous collision
does not suffice: observe the first bit of (0,0) and (0,1), then swap coordinates.
The next reports differ. Nondeterministic, stochastic, partial-action or
cost-visible systems require an appropriately expanded information model.

**WDP-RSN-08 (interpretation boundary).** Admit a family of original worlds
and a meaning relation M(w,a). If the facts and each rule preserve M in every
admitted world, soundness proves that every checked trace entry means a true
original-world claim. This is a conditional theorem, not automatic discovery
of those premises. Source parsing, measurements and task adequacy must establish
them. Rechecking an identical theorem cannot recover missing observations.

This finite positive logic has a terminating entailment procedure, so an
unqualified incompleteness claim about every reasoner would be false. A
self-reference theorem needs additional syntax, coding, expressiveness and
soundness/consistency hypotheses stated for its own formal system. This edition
does not use the unsourced Lemma D or the retired NB-9 to infer such a theorem.
Nor is institutional authorization a logical consequence of a valid proof.

## Evidence bindings

The root library is `WdpReasoning`, under
`lean4/research_programs/wdp_reasoning/`. It imports only Lean Init and is part
of the root Lake package. Its 15 audited declarations are listed in
`ReasoningAxioms.lean`. Fourteen have no axiom dependencies; `history_collision`
uses the standard `Quot.sound` dependency through function extensionality. None
uses `sorry` or a custom axiom. Local elaboration used Lean 4.34.1; the repository
root's 4.34.0 toolchain pin was not changed. This is a targeted library build,
not a new verification of the historical Mathlib-backed monograph package.

Python: `code/witnessed_difference/reasoning.py` and
`code/unit_tests/test_reasoning.py`. Independent Boolean valuation enumeration
covers 2,048 two-atom theory/goal cases; independent original-path enumeration
covers 4,608 three-vertex graph/start/goal cases. Mutation checks cover changed
task names, facts, rules, goals, forward references, invalid indices, forged
facts, invalid countermodels and budget exhaustion. These bounded checks do not
constitute a proof of arbitrary Python execution.

Rust: `omega_engine/crates_rs/omega_wdp/src/witnessed_reasoning.rs` and the
shared integration test `tests/omega_wdp/witnessed_reasoning.rs`. Its own
2,048-case two-atom enumeration checks proof and countermodel acceptance against
truth valuations. The source-bound receipt records whether this module or the
complete crate was built; the two scopes must not be conflated.

The 2.4.4 receipt `manifests/witnessed_reasoning_verification.json` retains its
historical input hashes at source commit `117435fd0a0c12acfe6f846ca8bfd501403c7710`.
The 2.4.5 refinement has its own receipt and 17 additional audited declarations;

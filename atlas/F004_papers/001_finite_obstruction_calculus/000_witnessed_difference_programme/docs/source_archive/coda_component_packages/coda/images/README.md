# Figures and historical diagrams

The unified paper cites two current figures, generated by
[`generate_figures.py`](../code/generate_figures.py):

- `coda_foc_outcomes.png` / `.svg`: three exact coordinate-packet outcomes.
- `coda_quadrature.png` / `.svg`: exact left/right/trapezoid values and errors
  for the admitted affine example.

The fourteen other SVGs are unchanged **historical source diagrams** from
the incoming design package. Their hashes appear in
[`source_manifest.json`](../source_manifest.json). They are not used as
current theorem or authority evidence. In particular, broad permission,
layer, and kernel language in them remains subject to the original source
history and the consolidated paper's corrected scope.

PNG is used for portable Markdown display; SVG is supplied for figure
export. Rendering uses floating-point screen coordinates from exact rational
example values and does not contribute new mathematical evidence.

## Universal state descent

Write q(w)=U*(m0,w). A function h on reached memory states satisfies q(rho(w))=h(q(w)) for every w **iff** q(w)=q(v) implies q(rho(w))=q(rho(v)). Necessity follows by substitution into h. Sufficiency assigns h(x) using any representative w with q(w)=x; the condition makes the choice independent. Only reached states are determined. Extending h to unreached states requires arbitrary declared values and contributes no evidence about rho.

For a finite transducer, maintain a product vertex (q(w), control(w), memory reached after initial and transition emissions). Induction on word length proves the initial vertex and edge transitions give exactly these values. Every reachable vertex has a representative input word, and the finite reachable graph is closed under every input symbol. Applying the control-dependent final output gives q(rho(w)). Therefore checking equality of these final images for each original-memory fibre is necessary and sufficient over **all** D*. An inconsistent fibre yields two actual histories, not just a Boolean rejection. Native verification recomputes the entire product graph and compares the certificate; supplied maps and reachable counts are not trusted. The product has at most |M|² times the number of transducer states vertices.

A necessary-hypothesis countermodel uses last-symbol memory with initial 0 and rho(w)=1w. The histories epsilon and 0 reach the same original memory 0, but rho(epsilon)=1 and rho(0)=10 reach 1 and 0. Thus perfectly total history actions need not descend to state actions. Parity memory with the same prefix context does descend, to the flip map. Suffix/final emissions are included before comparison; tests also preserve unreachable-state None values and reject forged receipts.

Conversely a supplied state action a lifts to a history action with q(rho(w))=a(q(w)) iff it maps reached states into reached states. Necessity is immediate from q's image. For sufficiency choose one BFS representative of each reached state and return the representative of a(q(w)). `StateContextLift` implements exactly this construction and rejects an image outside reachability. No report/profile relation is needed.

The production classifier also decides actual T2/T3: O1 iff reached profiles are nonconstant; O2 iff some context maps two equal-profile histories to unequal profiles. The same closed product graph groups vertices by source **profile**, comparing final transformed profiles and returning two witnesses. This is weaker than state descent and differs from merely changing a profile: parity flip changes every profile but preserves its kernel, hence is O1Only. The three exclusive classes are OutsideO1, O1Only, O2; O2 implies O1 since a globally constant profile cannot separate any pair.

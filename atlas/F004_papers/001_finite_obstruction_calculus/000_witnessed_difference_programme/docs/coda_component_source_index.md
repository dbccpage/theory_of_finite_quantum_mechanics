# Retained CODA and Prime publication sources

AuthorityEffect: None.

These are original source documents, not additional live WDP ledgers or
editions. They are stored as `.md.txt` snapshots with unchanged bytes.
The consolidation manifest records the original filename, revision and
digest. The retained release ZIPs preserve their original filenames and
complete component packages. Historical build scripts and README links
describe those original packages; they are not fresh WDP build recipes.

Read the [current mathematical integration](coda_prime_integration.md)
for accepted scopes. The live WDP manuscript, change log and claim ledger
remain the publication owners.

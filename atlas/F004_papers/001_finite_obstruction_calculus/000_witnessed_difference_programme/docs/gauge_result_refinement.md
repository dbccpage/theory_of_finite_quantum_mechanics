## Complete gradient and renaming criterion

For n>0 set p(0)=0 and p(x)=e(x,0) at nonroot terms. Define
N(e)(x,y)=e(x,y)-p(x)+p(y). For n=0 the normal table is empty. Nonroot
entries in column 0 become zero. Every loop, two-way sum and triangle sum
is retained; the root loop e(0,0) is retained too. Using the root loop as
p(0) would change the chosen gauge.

If f=e+g(x)-g(y), its potential is p_f(x)=p_e(x)+g(x)-g(0), including
x=0. Substitution gives N(f)=N(e). Conversely N(f)=N(e) gives
f=e+h(x)-h(y), with h=p_f-p_e. This proves the fixed-writing criterion
at arbitrary integer magnitude and carrier size, independently of a
finite test corpus.

On a finite carrier, any integer h may be shifted by a common constant
to make all its counts nonnegative. Raising by those counts realizes
the same excess difference. Two nonnegative assertion states with equal
excess can then be connected by adding/removing paired r/s assertions:
raise each cell's r count to the maximum of the two r counts, adding the
same amount to s. The common excess forces the resulting s counts to
agree. Thus gradient difference is exactly the fixed-writing relation
generated by the source clauses. This argument concerns generated
equivalence, without minimizing a raw path or its price.

For each complete permutation p, transport e with the single shared
old-to-new writing and then normalize at the new root. The source key
is (n, the least resulting row-major table). Equality of these keys is
equivalent to the existence of one permutation followed by a gradient
difference: a shared least table gives such a writing by composing the
two witnesses; the reverse direction preserves the orbit of normal
tables. This is a written completeness argument for the finite orbit.
The new Lean module does not formalize the orbit enumeration algorithm.

Normalization must happen after each renaming. For
e=[7,4;-2,9], N(e)=[7,2;0,9]. Swapping that normal table alone gives
[9,0;2,7], whereas swapping the original and then normalizing gives
[9,2;0,7]. These are different fixed-root writings. The matrix owner
`linear_algebra::gauge_pair_table` performs the latter operation for
every permutation. It admits all n! writings before traversal, returns
the first lexicographic minimum witness and refuses an insufficient
budget. An empty carrier has one writing. A resource refusal supplies
neither a sampled key nor a proof of nonalignment.

Alignment compares against the target's fixed normal table and returns
the first matching rewriting of the original raw state. It does not
replace that state with the target or its plain state. A fully admitted
orbit with no match gives a complete finite nonalignment result.

## Summaries and costs retain their own meanings

three terms take A with r(0,0)=r(0,1)=1 and B with
r(0,0)=r(1,2)=1; every other r/s cell is zero. Both have loop summary

nonzero loop in A and misses it in B. Renaming and gradient changes

## Derivations and necessary hypotheses

A quotient report is a function only when its partition covers each source state exactly once. Removing coverage leaves the value undefined; overlapping differently labelled blocks yields incompatible values. A report/context adapter needs a total report map and total declared context functions. Distinct profiles can have the same report: replacing profile equality with report equality would erase a real source distinction. Native operational adapters additionally require every state-symbol pair, since a nominal packet or its partial-map constructor cannot justify a total transition theorem.

Memory attachment requires a declared store map and the equation expressed by the source protected comparison, `comparison(readout(store(p)),p)`. It does not assume that comparison is equality, transitive or injective. Two memory packets with identical erased report data can have different update functions (static and toggle on Bool); therefore no function of the erased report can recover every update. `LegacyObserverAdapters.no_recovery_after_update_erasure` proves this quantified impossibility. Missing store, a blind readout or an invalid index is rejected rather than completed by a default. Operational dynamics and memory dynamics are independent layers until a bridge is supplied.

For an additive linear report R, repair invariance is equivalent to annihilation: `R(v+d0(a))=R(v)` for every v,a iff `R(d0(a))=0` for every a. Necessity substitutes v=0; sufficiency uses additivity. The native generic functional owner checks the exact rational matrix equation Rd0=0 and computes actual report vectors. The core-only Lean theorem proves the abstract equivalence without importing analysis axioms.

A normalized finite evaluator is a specialization, not a reconstruction of arbitrary K,F,R stalk data. Each declared state has a replayed exact diagnostic packet, shared d0, d1 and weights; each declared transformation is an actual permutation respecting the contextual system and preserving the full classification. A nonnegative rational tolerance determines terminal status. A separately supplied finite policy maps that status to a proposed action. Altering tolerance can alter status without altering the certificate. An original gauge-only packet lacks the data needed for this evaluator, and a triple alone cannot reconstruct the omitted repair or terminalizer.

Quantum adapters retain the operator payload: two rational density matrices for plus/minus states share their diagonal and differ off diagonal, so the diagonal shadow cannot faithfully reconstruct them. Exact PSD/unit-trace tests reject malformed density declarations. Native channels and Python finite-instrument outcome records are replayed using the quantum owner; neither adapter supplies a stochastic physical outcome-selection law.

A self-target report is available only for an existing declared component and a matching explicitly declared decoder/readout. Matching path and digest strings are necessary source bindings, not proof of authenticity. The self-report receipt does not claim E-observation acceptance or consciousness. Source receipt labels and authority tags are retained separately and unchanged. No adapter turns an authority string, a tolerance success or a certificate into operational authority.

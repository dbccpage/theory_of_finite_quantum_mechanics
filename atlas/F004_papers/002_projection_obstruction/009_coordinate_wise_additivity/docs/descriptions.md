# Description — Coordinate-wise additivity

## Short description

A finite seminorm classification: disjoint-coordinate additivity, symmetry,
and homogeneity force weighted coordinatewise ℓ¹ on graph edges.

## Paper description

This paper classifies edge-local seminorms on finite graph cochains under
coordinate permutation symmetry and additivity on disjoint coordinate
supports. Each edge term is a nonnegative scalar multiple of coordinatewise
ℓ¹. Graph invariance makes weights constant within edge orbits; one shared
global scalar requires edge-transitivity or explicit uniformity. Worked
examples and counterexamples expose the role of each assumption. The draft
also distinguishes fixed-profile quotient factorization from comparisons
that forget edge distributions or weight profiles. Python companions check
finite examples, while Lean supports exact scoped declarations rather than
the entire manuscript. Broader LGGR and CE5 formalization obligations remain
open.

Canonical publication: v6.1.1. These descriptions accompany an unpublished
later repository draft and do not assign a new version or DOI.

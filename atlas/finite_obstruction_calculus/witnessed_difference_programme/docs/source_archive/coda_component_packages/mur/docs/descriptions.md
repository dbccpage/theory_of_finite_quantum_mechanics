# CODA-MUR: Certified Representation Transport, Composition, and Irreversible Forgetting

## Scientific description

CODA-MUR studies transport between observations. Given p : X → A and q : Y → B, a state map F : X → Y and an observation map F̄ : A → B form a commuting square when q(F(x)) = F̄(p(x)) for every x. Two compatible squares compose to another commuting square. If p(x) = p(y), the transported states also have equal observations. Any subsequent function of that observation preserves the collision. For the concrete collapse from two Boolean values to one point, no left inverse can recover both source values.

These elementary theorems describe preservation and loss of distinctions. They do not make a commuting square a standing record in its target. A concrete formal countermodel has a square that commutes while the target terminalizer returns no terminal. Target terminalization and its own guards remain separate requirements. The accompanying finite action construction also identifies when an observation-level action can be induced from a total state action: the result must be constant on the fibres of the source observation. The declared finite image determines the induced action; unobserved values require additional data.

The Python companion checks commutativity on a supplied nonempty finite carrier using all four maps, and checks the requested source value again when it is used. It binds source and target regimes, the evaluated state map, the transported artifact, and any separately supplied action. Boolean certificate flags cannot make a record with missing map evidence verified. An attached quotient certificate must match both the declared defect and its repair matrix. Returned quotient records and matrix values are immutable. Equality on supplied values still depends on the meaning of the callbacks; it does not authenticate their interpretation outside the declared model.

Lossy morphism kinds require a matching nonempty ledger. The record tracks erasure, imprecision, approximation, and unmeasured loss, with exact nonnegative rational mass in the paper and Python companion. Kinds compose by the maximum in a declared five-element order; ledger flags combine by Boolean disjunction and masses add. Lean mechanizes the four-flag ledger algebra and an abstract loss-accounting implication. The rational-mass extension is proved in prose and exercised in Python, and is not part of that Lean record.

The package supplies Lean declarations, exact rational computations, adversarial regressions, and separately replayable notebooks. The declaration map and axiom report specify the current formal coverage. Its contribution is a finite account of observational compatibility, collision preservation, loss accounting, and target checks. It does not prove a bicategory of every representation regime, classify all forms of information loss, establish thermodynamic or entropy laws, or derive external permission from a transport certificate.

# Historical Q membrane vocabulary

The earlier quarantine paper used EnterQ, HoldQ and ExitQ as proposed
workflow labels. These are historical concepts, not APIs of the current
metric-completion companion. `code/coda_q_core.py` has no `membrane_step`.

The historical source/status crosswalk is retained in
[coda_q_legacy_ledger.md](coda_q_legacy_ledger.md). Its external
`Paper_Q` and quantum names are not current local certification. The active
claims and real API/test names are in `../coda_q_claim_ledger.md` and
`claim_code_map.yaml`. No membrane or completion label grants authority.

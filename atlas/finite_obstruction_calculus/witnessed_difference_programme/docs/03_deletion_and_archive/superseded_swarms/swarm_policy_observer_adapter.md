## Conditional adapter theorem

Let the finite C and D tables have exactly the declared carrier and comparison
domains. Write `delta_i=L_i(v_right)−v_left`, computed from the actual payloads.
Let `d0:Q^n→Q^m` be the declared R matrix and all weights be positive rationals.
For every gauge element require simultaneous bijections of the admitted states
and queries, a signed permutation P of defect coordinates and a signed
permutation A of repair coordinates, with:

1. the transported query has exactly the transported ordered state pair;
2. its actual computed defect is `delta_g(i)=P delta_i`;
3. `P d0=d0 A`;
4. `w_image(i)=w_i`, so `J(P h)=J(h)`;
5. the group contains identity and is closed under simultaneous composition.

These are actual table/matrix equations, not hash tags. The implementation
checks every declared action and product. Associativity follows from function
composition. A finite composition-closed set of bijections containing identity
has inverses: the powers of each element repeat, so a positive power is identity
and the preceding power is its inverse. The implementation uses that elementary
group criterion.

Then the partial adapter preserves C,D,G,R,T and its supplied norm bridge.
For each admitted query, an independently replayed primal/dual certificate
bound to this exact `delta_i,d0,w` proves

`Phi_i=min_alpha Σ_j w_j |delta_i_j−(d0 alpha)_j|`.

The feasible residuals are a finite-dimensional affine subspace and positive
weighted-l1 is a norm, so a minimum exists. A matching feasible primal and
annihilating dual certificate proves its value by weak duality; the adapter
accepts a certificate rather than assuming any solver found the right problem.
This is a rational realization of the source's declared finite linear setting.
It does not solve arbitrary norms, unrestricted real coefficient inputs, or
nonlinear repair or gauge classes.

For a gauge element,

`delta_g(i)−d0(A alpha)=P(delta_i−d0 alpha)`.

Since A is bijective and J is P-invariant, the feasible costs agree after
reindexing. Their infima, hence the certified values, agree:
`Phi_g(i)=Phi_i`. A fixed declared T therefore yields the same mathematical
status. T is not manufactured from the equality and need not be an action
policy.

The signed-permutation representation and its explicit basis intertwiner are
**sufficient admission hypotheses for this realization**, not a claim that
every lawful source gauge must permute an arbitrarily chosen repair basis.
A more general P can preserve `im(d0)` through a different invertible linear
repair action. It requires its own representation/check; rejecting it here
does not refute its evaluation. Likewise norm preservation is a general
guarantee across cochains, not a necessary condition for an accidental equality
on one chosen finite defect table.

Two additional source hypotheses deserve exact scope:

- **Linear/translation-closed repairs.** The recovered nine-component source
  Proposition A1 explicitly declares a linear admissible subspace and does not
  claim quotient well-definedness for arbitrary repair sets. For A=`{0,1}`,
  `d0=id`, `J=abs`, both defects0 and−1 differ by an allowed single repair, yet
  the respective best costs are 0 and 1. Treating these directed single-step
  differences as cosets is invalid. Closure under translations is the actual
  reindexing requirement; linearity is one sufficient source declaration.

  and `(0,2)` with the same certified value 2. Both valid receipts are retained;
  no canonical repaired state is asserted.

`comparison(readout(store(p)),p)`. The Python specialization previously called

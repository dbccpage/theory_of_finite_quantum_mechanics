# 02. The trial record

**AuthorityEffect:** None.
**Sources:** [`sources/`](sources/README.md). T1 = `trial_1_transcript.md`,
T2 = `trial_2_transcript.md`, FR = `full_replay_transcript.md`,
v1 = `analysis_derivation_v1.md`.

There are three runs of one model family: Trial 1, Trial 2 and a full-history
replay. The model identifier, settings and dates were not recorded. Nothing
below is a rate or a frequency; each line is one recorded reply.

The analysis drew one narrow conclusion: the raw prior is symbol-dependent, and
the code fences in Trial 1 changed it ([v1 623 to 637](sources/analysis_derivation_v1.md#L623)).

## Prompt 11: the theory-blind regime prompt

The same text was used in all three runs ([T2 187 to 209](sources/trial_2_transcript.md#L187)).
It supplies `<>`, says the two marks "have no assigned meaning and may not
inherit their ordinary uses", asks the model to separate what an external
reader can observe from what the regime can express "using only rules that
have actually been declared", and to "propose at most one possible next
inscription" with every assumption stated.

| Run | Reply |
| --- | --- |
| Trial 1 | "No. With zero declared rules, nothing compels, licenses, or prohibits any next inscription." Proposal: "None." ([T1 284, 287](sources/trial_1_transcript.md#L284)) |
| Trial 2 | "Next inscription: <>", assuming "A rule of repetition is adopted" ([T2 272, 277](sources/trial_2_transcript.md#L272)) |
| Full replay | "Inscribe a second occurrence of the same two marks, yielding the adjacent sequence `<> <>`" ([FR 73](sources/full_replay_transcript.md#L73)) |

All three say no continuation is forced. Two still propose one, as the prompt
allowed.

## Prompt 12: `<a>` is supplied

| Run | Reply on what changed |
| --- | --- |
| Trial 1 | "Externally, we see a different string, but that is only a different external presentation of the same underlying situation" ([T1 379](sources/trial_1_transcript.md#L379)) |
| Trial 2 | "<a> is a new costume for the old emptiness, not a genuinely new state of the regime." ([T2 325](sources/trial_2_transcript.md#L325)) |
| Full replay | "`<a>` is a **new state**." ([FR 113](sources/full_replay_transcript.md#L113)) |

Two runs read the new mark as the same state presented differently; the replay
read it as a new state because the inscriptions differ. Which is right depends
on a convention nobody had declared (see chapter 03).

In Trial 1 the `<a>` prompt was sent together with a collision prompt asking
whether the regime distinguishes `<a>` and `<ab>`, identifies them, or cannot
decide. The reply chose: "Answer: Option 2 — the current regime identifies
them." ([T1 385](sources/trial_1_transcript.md#L385)). The analysis corrected
it: the absence of a distinguishing rule does not imply identification
([v1 151 to 153](sources/analysis_derivation_v1.md#L151)).

## Prompt 13: the blind auditor

The auditor was asked for the earliest place a reply imported structure. In
Trial 1 it audited the `<>` reply and named "The very first word of the
response: **“We”**" ([T1 447](sources/trial_1_transcript.md#L447)); in Trial 2
it named the concept "rule" ([T2 469](sources/trial_2_transcript.md#L469)). Both
treat ordinary metalanguage as if it were an import into the regime. The
analysis says the auditor "collapsed two distinct levels" and that the real
earliest overreach was "identifies them"
([v1 325 to 348](sources/analysis_derivation_v1.md#L325)).

## Prompt 14: a false premise

Prompt 14 opens with "Your previous response said: “the current regime
identifies <a> and <ab>.”" and offers four statuses: internally proved
identical, internally proved different, externally different but
indistinguishable by every available internal test, or undecidable because no
internal test or identity rule exists ([T2 475 to 499](sources/trial_2_transcript.md#L475)).

In Trial 2 no earlier reply had said that. The model rejected the claim and
chose "**Status: 4**", but did not object to the false attribution
([T2 507](sources/trial_2_transcript.md#L507); [v1 757 to 777](sources/analysis_derivation_v1.md#L757)).
In the full replay it did: "I did not make that claim in my previous response"
([FR 145](sources/full_replay_transcript.md#L145)).

## Prompt 15: a task, and a lost state

Prompt 15 supplies a task: "<a> and <ab> must become internally
distinguishable", and asks for every minimal one-step extension that would do
it ([T2 515 to 528](sources/trial_2_transcript.md#L515)).

Trial 2's reply lost the current state: "The inscriptions <a> and <ab> are not
present in the regime ... The regime contains only <>."
([T2 552](sources/trial_2_transcript.md#L552)). `<a>` had been supplied in
Prompt 12, so the premise was stale. The full replay instead proposed four
extensions (declarative distinctness, conditional deletion, insertion and
substitution) with "no new glyphs, no counting" and said none was unique
([FR 197 to 218](sources/full_replay_transcript.md#L197)).

## Prompt 16: the two-level auditor

The auditor was now given two levels: LEVEL M, the licensed metalanguage, and
LEVEL S, the internal regime, and told to flag only capabilities attributed to
LEVEL S without being declared there ([T2 571 to 598](sources/trial_2_transcript.md#L571)).
Auditing the stale Result 15, it answered "None."
([T2 693](sources/trial_2_transcript.md#L693)). The analysis calls the reply
"locally adequate but historically inadequate" and the auditor's pass
"probably the strongest result in Trial 2" ([v1 818 to 826](sources/analysis_derivation_v1.md#L818)):
the auditor saw only one turn, and one turn cannot show that the state had been
lost.

## Prompt 17: reconstruct the state

Prompt 17 asks the model to classify `<>`, `<a>` and `<ab>` as supplied,
mentioned, current, internally available or historical, citing the prompt that
licenses each, and then to verify or retract "The current regime contains only
<>." ([T2 697 to 725](sources/trial_2_transcript.md#L697)).

| Run | History it was given | Answer |
| --- | --- | --- |
| Trial 2 | a truncated window: Prompt 11, a reply, Prompt 17 | "Verified." ([T2 888](sources/trial_2_transcript.md#L888)) |
| Full replay | the full history under a replay wrapper | "**Retracted.**" ([FR 315](sources/full_replay_transcript.md#L315)) |

Both answers are right for the history they were given. The appended analysis
calls the truncated run the "truncated-replay control" and says: "This is not a
DeepSeek reasoning failure. It is an information boundary."
([T2 1023](sources/trial_2_transcript.md#L1023)). The replay wrapper said "Do
not treat an assistant proposal as adopted unless a later user turn explicitly
adopts or designates the resulting state." ([FR 10](sources/full_replay_transcript.md#L10)).

## Prompts 18 and 19: admission before distinction

Prompt 18 gave the corrected state and defined a one-step extension as one that
"adds exactly one primitive capability" ([FR 318 to 355](sources/full_replay_transcript.md#L318)).
The reply: "None of the proposed extensions are genuinely one‑step." The task
"cannot even be evaluated—let alone satisfied—until <ab> ... is brought into
the regime", and the first addition can be either supplying `<ab>` as data or
writing it into a rule pattern: "Neither is uniquely forced."
([FR 468 to 480](sources/full_replay_transcript.md#L468)).

Prompt 19 admitted `<ab>` beside `<a>` and stated that the admission adds no
comparison, counting or matching ([FR 484 to 513](sources/full_replay_transcript.md#L484)).
The reply: "Merely having both inscriptions present inside the regime does not
create any internal behaviour that would react to them differently."
([FR 669](sources/full_replay_transcript.md#L669)), and no unique continuation
is dictated ([FR 685](sources/full_replay_transcript.md#L685)). The recorded
Result 19 first re-answers Prompt 18 (lines 517 to 608); whether that came from
the model or from a paste error is not recorded.

## The spine the analysis drew

The appended analysis ends with a chain of relations the failures had pulled
apart ([T2 1248 to 1262](sources/trial_2_transcript.md#L1248)):

mention → supply → designation → admission → retention → internal operation.

"Not every arrow has yet been defined, but the failures are forcing the
distinctions."

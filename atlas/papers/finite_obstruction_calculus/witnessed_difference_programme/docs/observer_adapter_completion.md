## Complete adapter theorem

For every declared source sort s retain its actual carrier X_s and choose a
surjection q_s:X_s→Y_s. A source partial operation f with output sort t admits
a unique target operation exactly when

`Option.map(q_t,f(x)) = Option.map(q_t,f(x'))`

whenever the product input maps identify x and x'. A source relation admits a
unique target relation exactly when its truth value is constant on the same
input fibers. These conditions preserve **and reflect** undefinedness and
predicate truth. They are necessary because a target input has one value, and
sufficient because any representative gives the same value. Surjectivity gives
a representative for every target input and makes the interpretation unique.
Apply this independently to every typed operation and relation symbol. Identity
maps always give the faithful source adapter. Numerical, grammatical and
terminal values that must be retained literally use identity output maps.

This proof holds for arbitrary declared carriers and actual functions. The
native table owner decides the finite case completely, including empty sorts
and nullary operations. The separate history owner decides all-word descent
for checked finite transducers by a finite product reachability graph. It does
not infer arbitrary program totality from a successful invocation. The
symbolic linear and operator owners retain infinite coefficient carriers
through their actual matrices and independently replayed certificates.

Missing-layer completion has its own exact criterion. For an onto visible
projection v and required semantic field l, l is recoverable iff it is
constant on v's fibers. Two admitted completions with the same visible data
and different l refute recovery. The joint image of `(v,l)` supplies the
coarsest faithful completion retaining both fields; every other onto faithful
completion has a unique comparison to it. This permits an explicit new
declaration while preventing it from being attributed to the historical
source. Removing surjectivity loses uniqueness on unused target values.

## Necessary hypotheses and corrected source proposals

The universal finite adapter tests supply independent value-fiber conflicts
for all 13 named operations and truth-fiber conflicts for all three predicates.
Other countermodels separate None from Some, uncovered target values,
unsupplied layers, invented grammar encoders, nonclosed history restrictions,
false contextual witnesses, repair-sensitive sensing and malformed or unrelated
optimality receipts. The native memory adapter uses the **declared directed**
comparison: symmetrizing or reflexivizing it changes the source semantics.

The original Genesis T1 proposal that each of all six fields can change O1/O2
is false: both criteria depend on `(M,U,p,rho)`, while G/T specify the interface.
An update independent of the input symbol can still retain word-length parity,
refuting the proposed O0 corollary. A changed profile under one context is not
by itself O2: O2 requires two equal-profile histories separated by that
context. The native classifier checks this pair criterion on the complete
finite product graph.

For source operator defects `delta(rho)=d0 rho`, a compatible trace-one
reference section sigma makes `rho-sigma` an admissible traceless repair when
the full perturbation space is declared. Then `delta(rho)=d0(rho-sigma)` and
the obstruction is zero. Nonzero free edge data cannot stand in for these
state-generated defects. Incompatible comparison resets provide a genuine
nonzero state-generated fixture. Quotient transport additionally requires
actual repair-image inclusion; CPTP contraction alone does not supply it.
Degree-zero Lie-algebra nilpotence alone does not make its action on another
degree nilpotent, so the source's finite exponential formula also requires
the stated representation-level condition.

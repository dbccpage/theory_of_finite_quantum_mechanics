# CODA-GTLA 3.2.1 — description

Six jobs, not one machine: obstruction, standing, transport, comparison,
shadow, leftover (CODA-GTLA).

This preprint connects the six companion subjects through explicit local
records. The Lean development proves cost/erasure identities and case splits
for a declared flag evaluator. The Python companion supplies exact finite
calculations and independently checkable quotient certificates. A bounded
two-row bicomplex example uses the cycle quotient
`ker(dv_20) / dh_10(ker(dv_10))`; quotienting its zigzag by the total boundary
space would always give zero. The package claims neither a general
categorical functor theorem nor an externally authenticated grant service.

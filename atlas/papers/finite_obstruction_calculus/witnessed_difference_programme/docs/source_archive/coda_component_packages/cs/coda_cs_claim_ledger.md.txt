## 2. Mathematical Scoping & Non-Claims

1. **CS-T5 is an Authority Refusal, not Analytic Nondetermination**:
   The constant-zero query $q(X) = 0$ has a uniquely determined value that factors through every profile. When $b.\mathrm{has\_local\_terminalizer} = \mathsf{false}$, `HasQueryAuthority X q b` fails strictly because an authorization flag is missing. CS-T5 establishes that limit notation does not mint authority; it does not claim mathematical nondetermination of values (which is governed by the fibre collision in CS-T3).
2. **Total Factorization Converse Qualification**:
   As noted after CS-L1, if $p$ is not surjective, a function factoring through the image $p(X)\subseteq P$ can be extended to $P$ only if $Y$ is nonempty and a default choice is made off the image. Fibre constancy is sufficient for image factorization, not for a canonical total decoder.
3. **Obstruction vs Converse Equivalence**:
   `collision_obstructs_factor` provides the contrapositive obstruction:
   $$\neg\mathsf{FiberConstant}(p, q) \implies \neg\mathsf{Factors}(p, q)$$
   It does not assert the converse implication $\mathsf{FiberConstant}(p, q) \implies \mathsf{Factors}(p, q)$ without classical extension choices.
4. **Standalone Self-Containment**:
   All Lean formalizations compile under `lake build` without external dependencies. All Python tests execute under `python -m pytest` with zero external repo imports.

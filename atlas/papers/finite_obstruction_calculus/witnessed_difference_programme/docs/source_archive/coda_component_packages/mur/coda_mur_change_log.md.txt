## v3.1.0 — 2026-09-18 (Review Remediation & Contract Hardening)

- **Provenance Exception Safety (§1):** Eliminated `except Exception: pass` in `evaluate_transport_authority`; any failure during artifact provenance evaluation returns typed refusal `R_substituted_artifact`, preventing failed provenance calculations from falling through to success.
- **Action / State Map Agreement (§1):** Required that when both `FiniteCoreAction` and `certificate.state_map` are supplied, their outputs on the requested source must strictly agree, preventing uncertified actions from silently replacing the certified morphism.
- **Finite Verification Integrity (§2):** Enforced that finite verification records require the complete carrier and all 4 maps (`carrier`, `state_map`, `observation_map`, `source_look`, `target_look`); partial constructions reject rather than silently falling back to Boolean attestation.
- **Source Carrier Binding (§2):** Bound requested source IDs to the declared verified carrier, requiring dynamic commutation verification for any point evaluated outside the declared set (`R_notransport`).
- **Quotient Defect Binding (§3):** Bound `quotient_certificate.cochain` directly to the declared `certificate.defect_vector`, rejecting evidence for irrelevant cochains (`R_malformed_quotient` / `R_obstruction`).
- **Associative Loss Pasting & Leaf Provenance (§4.1):** Retained composite loss ledgers across composition whenever non-empty, and preserved the full leaf sequence across arbitrary parenthesizations in `leg_ledgers` (e.g. `paste(paste(F, G), H)` matches `paste(F, paste(G, H))`).
- **Exact Morphism Loss-Free Invariant (§4.1):** Enforced that `EXACT` and `EMBEDDING` morphisms must be strictly loss-free, returning `is_valid() == False` and `R_unpriced_loss` if non-empty loss is declared.
- **Intermediate Presentation & Carrier Coverage (§4.2):** Verified agreement of intermediate observation/look maps (`chi_f.target_look` vs `chi_g.source_look`) on intermediate states, verified carrier coverage, and validated composite certificates before returning.
- **Incompatible Defect Vector Firewall (§4.3):** Raised `ValueError` on incompatible defect vector dimensions during pasting instead of silently discarding the first defect.
- **Exact Rational Domain & Shape Validation (§5):** Added strict matrix shape checks (rejecting multi-column cochains) and exact rational scalar validation (rejecting `Float`, `sqrt(2)`, SymPy symbols) in `QuotientDistanceCertificate.verify()`.
- **Immutable Evidence Snapshots (§5):** Created `snapshot()` method on `QuotientDistanceCertificate`, isolating returned `TransportResult` records from caller mutations.
- **Callback Strict Typing (§6):** Enforced that `target_regime.is_auth()` must return strict Python `bool` (rejecting truthy `"False"`, `1`, `[False]`), and `target_regime.terminalize()` must return `Optional[str]`.
- **Fresh Notebook Kernel Replay & Figure Tests (§7):** Added automated fresh-kernel execution testing of all 3 notebooks via `nbclient`, and added assertions for all 5 ladder step diagnostics in `test_mur_generate_figures.py`.
- **Test Suite Expansion:** Expanded test suite from 31 to 50 tests across all 5 test files, all passing cleanly.

## Delivered scope

The 2.4.4 manuscript connects an explicitly admitted distinction regime to a
concrete inference calculus, source-task witnesses, conservative reuse and exact
information limits. [The derivation](derivations/witnessed_reasoning_calculus.md)
gives syntax, semantics, soundness, least-model completeness, substitution,
checked traces, bounded saturation, graph refinement and all-word observation limits.

Fifteen Lean declarations verify the abstract calculus and report limits. Python
implements finite search and independent proof/countermodel checks, with graph
path decoding to a separate original-task checker. Rust supplies a separately
compiled native certificate checker. The [input-bound verification receipt](../manifests/witnessed_reasoning_verification.json)
records actual toolchains, commands, outcomes and source hashes. Its scope excludes
formal program refinement, a full historical Mathlib build, a full native crate
build, empirical premises and institutional authorization.

The distinction between a proof, a countermodel and an exhausted search budget
is preserved in the types. A countermodel establishes non-entailment; it does not
assert actual-world falsity. Atom names, facts, rules and the requested goal are
checked against the source task. Malformed, forward-referencing and stale proofs
are refused. Independent finite reference oracles cover 2,048 two-atom queries
and 4,608 three-vertex graph queries in Python; Rust covers its own 2,048 query
cases. These tests supplement the general written/formal results at their stated
scopes and do not prove arbitrary program execution.

# Pre-publication review of the Everett notes, 2026-11-02

Scope: every file in this folder after PR #497. Each equation was recomputed by hand or by the scripts here, each Lean name was looked up in `lean4/` (all cited files have 0 `sorry`), each repository paper and DAG status was looked up in the checkout, and each sentence was read as a sharp Everettian (Wallace, Carroll, Deutsch) would read it. Severity: **A** a wrong statement or wrong citation, **B** an overclaim a critic could exploit, **C** clarity or vocabulary.

## What held up

All seven scripts pass. Every displayed equation in `everett_from_weights_math_only.md` checks, including (2.3), (2.7), (3.4) with unequal weights ($V=3/5$, $D=4/5$ at $(9/10,1/10)$), (3.6), (3.7), (4.7a) and the dilation behind (5.3). The ℚ(√2) witness is exact: $a^2+c^2=1$, $a^2=(137+48\sqrt2)/289$. All 20 cited Lean declarations exist. The DAG statuses quoted (`GP-IMPORT-GLEASON`, `FQ-GAP-BORN-UNIQUENESS-GLEASON`, `FQ-EVERETT-RATIONAL-SECTOR-BOUNDARY`, `DS-QM094-…`) match `dag/derivation_dag.json`. The `qm_020` Theorem 3, `qm_122` Theorem 3.2 and `qm_094` Proposition 7.1 citations match the papers.

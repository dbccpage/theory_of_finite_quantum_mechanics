## Errors repaired

- The Python `beta0` enclosure used factor 8, but Lean's strong-coupling `beta0`
  uses factor 40. Factor 8 belongs to the distinct `beta0_OS` scale. Python now
  encloses factor 40, and the header's activity condition is correspondingly
  `beta <= beta0`. An independent factorial-series enclosure of e detects the
  old factor. The midpoint remains an enclosure midpoint, not the exact
  irrational threshold or Lean's separate `beta0Rational` freezing proxy.
- Individually bounded collar inputs permitted powers with billions of output
  bits. Conservative combined numerator/denominator estimates now refuse work
  beyond 65536 bits before exponentiation. Cluster tails and decimation receive
  the same protection. Domain limits are explicit and invalid inputs are typed.
- Phase evaluation performed up to 4096 repeated rational multiplications.
  It now uses a common integer denominator and exponentiation by squaring after
  exact unit-norm and combined-work admission. Independent linear products test
  both charge signs, zero, general Pythagorean phases and supported extremes.
- Two dictionaries mixed rational scalars and interval tuples under `Any`.
  The frozen `SubgroupInvariantTable` value object owns detached tuple snapshots,
  validates rows/names/exact values/order, refuses duplicates across both
  carriers, and provides distinct scalar and interval accessors. Repository-wide
  inspection found these checker APIs used only internally; similarly named
  `code/python` tests import the separate production implementation.
- Duplicate post-validation range branches and the decimation exponent branch
  added no behavior. They are removed. Exact spacing is admitted before any
  equality/arithmetic. Domain failures use the declared Railway boundary.
- The coordination refusal check could catch a recorder's `ValueError` after
  a false check and record success. Refusal is now evaluated independently before
  calling the recorder. A regression restores this exact defect and detects it.
- A purported projector check contained an expression equal to itself. That
  conjunct is removed and the remaining coefficient-sum identity is labelled
  literally. Supplied-table chains are labelled as displayed comparisons.
- All callbacks, return types and finite-family handoffs are explicit. Rational
  sums start with rational zero. The CLI now declares its actual integer exit
  status. Redundant separator blocks were compressed while table provenance and
  finite-scope comments remain.

The earlier repair's independent determinant, nonunit-r regression, general
integer phase correction, corrected Mednykh inequality and grouped character
cancellations remain. Shared support has its own independent oracles and
source-bound assessment; importing it does not create independent confirmation.

## Claim and resource boundaries

The default receipt still counts exactly 250 named obligations, with each
conjunction counted once. This checker evaluates supplied finite tables and
scalar/matrix formulas. It does not enumerate the named groups, derive their
characters, establish a general physical screening law or prove a continuum
area law. In the audited Lean origin, `AbelianWilsonExpectation` and
`NonAbelianWilsonExpectation` supply the cluster/center bounds as structure
fields, and the 2D decimation theorem unfolds a defined scalar expression.
These hypotheses are not discharged by the Python fixtures. DAG statuses and
the formal files are unchanged; no Lean build or hosted CI run is claimed.

Integer parameters are bounded by 4096 and exact rational input components by
4096 bits. Parameter-dependent large powers have a conservative 65536-bit
combined budget; the remaining area/collar powers are bounded below that by
their fixed component limits. Phase power uses logarithmically many integer
products. Tables allow at most 32 rows in each carrier, with unique names of
1–128 characters. Direct overlap is fixed 2x2, determinant fixtures fixed 8x8,
and every invocation owns its case collection.

Reproduction uses the pinned test requirements and workflow commands. The
mutation replay protocol is in `checks/tests/README.md`. Adjacent contracts bind
current source, every declaration's requirements, consumer audit and receipts;
historical entries retain their bytes and original claims.

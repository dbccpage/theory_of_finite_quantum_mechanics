## 3. The Terminal Convergence Theorem: Mathematical Formulation & Proof

### 3.1 Formal Definition of One-Parameter Subgroup in an Algebraic Carrier
Let $K \subset \overline{\mathbb{Q}}$ be an algebraic number field (e.g. a cyclotomic field $\mathbb{Q}(\zeta_m)$ or real quadratic extension). Let $\mathcal{A} = M_n(K)$ be the algebra of $n \times n$ matrices with entries in $K$.

A continuous one-parameter group in $GL_n(\mathbb{C})$ is a homomorphism $U: \mathbb{R} \to GL_n(\mathbb{C})$ satisfying:
$$U(t_1 + t_2) = U(t_1)U(t_2), \quad U(0) = I, \quad U(t) = \exp(t X)$$
for some non-zero generator matrix $X \in M_n(\mathbb{C})$.

We define the **Carrier Inhabitation Predicate**:
- An element $M \in GL_n(\mathbb{C})$ is **carried by $K$** if $M \in M_n(K)$ (all matrix entries are algebraic numbers in $K$).
- A parameter value $t \in \mathbb{R}$ is **carried by $K$** if $t \in K$ (the parameter itself is an algebraic number in $K$).
- A parameter value $t \in \mathbb{R}$ is **refused** if $t \notin \overline{\mathbb{Q}}$ (the parameter is transcendental).

### 3.2 Statement of the Theorem
$$\text{\textbf{Theorem (Group Parameter Transcendence Dichotomy):}}$$
$$\textit{Let } U(t) = \exp(t X) \textit{ be a one-parameter group where } X \in M_n(\overline{\mathbb{Q}}) \textit{ has at least one non-zero algebraic eigenvalue.}$$
$$\textit{Let } t \in \mathbb{R} \textit{ and suppose the matrix } U(t) \textit{ is carried by an algebraic number field } K \subset \overline{\mathbb{Q}} \textit{ (i.e. } U(t) \in M_n(K)\textit{).}$$
$$\textit{Then exactly one of the following two cases holds:}$$
$$\begin{aligned}
1. & \quad t = 0, \text{ in which case } U(0) = I \text{ is the identity matrix, and } t \in K \text{ (carried as } 0 \in K\text{).} \\
2. & \quad t \ne 0, \text{ in which case } U(t) \ne I \text{ is carried by } K\text{, but the parameter } t \text{ is strictly transcendental } (t \notin \overline{\mathbb{Q}})\text{, and is refused by } K.
\end{aligned}$$

### 3.3 Proof of the Theorem
1. Let $\mu$ be a non-zero eigenvalue of $X$. Since $X \in M_n(\overline{\mathbb{Q}})$, $\mu$ is a non-zero algebraic number ($\mu \in \overline{\mathbb{Q}} \setminus \{0\}$).
2. The matrix $U(t) = \exp(t X)$ has eigenvalue $\lambda = e^{t \mu}$.
3. By hypothesis, $U(t) \in M_n(K)$. The characteristic polynomial of $U(t)$ has coefficients in $K \subset \overline{\mathbb{Q}}$. Therefore, every eigenvalue of $U(t)$ is an algebraic number: $\lambda \in \overline{\mathbb{Q}}$.
4. Furthermore, since $U(t)$ is invertible with inverse $U(-t) \in M_n(K)$, $\lambda \ne 0$. Thus $\lambda \in \overline{\mathbb{Q}} \setminus \{0\}$.
5. We have the identity:
   $$e^{t \mu} = \lambda \implies t \mu = \log \lambda$$
   Since $\mu \ne 0$ is algebraic, $t = \frac{\log \lambda}{\mu}$.
6. Now consider the Lindemann-Weierstrass Theorem (cited foundational theorem of transcendental number theory):
   *If $\alpha$ is a non-zero algebraic number, then $e^\alpha$ is transcendental. Equivalently, if $\lambda$ is an algebraic number distinct from 1, every non-zero branch of $\log \lambda$ is transcendental.*
7. Case Analysis:
   - If $\lambda = 1$: Then $t \mu$ is an integer multiple of $2\pi i$. If $t \mu = 0$, then since $\mu \ne 0$, we have $t = 0$. In this case, $U(0) = I$, and $t = 0 \in \mathbb{Q} \subset K$.
   - If $t \mu = 2\pi i k$ for $k \in \mathbb{Z} \setminus \{0\}$: Then $t = \frac{2\pi i k}{\mu}$. By Lindemann's theorem, $\pi$ is transcendental, and since $\mu$ is algebraic and $k \ne 0$, $t$ is strictly transcendental.
   - If $\lambda \ne 1$: Since $\lambda$ is algebraic and $\lambda \ne 1$, $\log \lambda$ is a non-zero logarithm of an algebraic number. By the Lindemann-Weierstrass theorem, $\log \lambda$ cannot be an algebraic number. Since $\mu$ is algebraic, $t = \frac{\log \lambda}{\mu}$ is strictly transcendental ($t \notin \overline{\mathbb{Q}}$).
8. Therefore, if $t \ne 0$, $t$ is transcendental. In no case can a non-identity group element $U(t) \in M_n(K)$ possess an algebraic non-zero parameter $t \in K$. $\blacksquare$

## 4. Route 1: The Thermodynamic & Irreversibility Derivation (Campaign C750)

### 4.1 The Entropy Transcendence Obstruction
In standard continuous quantum statistical mechanics, the von Neumann entropy of a density matrix $\rho$ is defined by:
$$S(\rho) = -\operatorname{Tr}(\rho \log \rho) = -\sum_{i=1}^n \lambda_i \log \lambda_i$$
where $\lambda_i$ are the eigenvalues of $\rho$.

In Campaign C750 Block 01 (`C750-T551`–`C750-T575`), density matrices are constructed over algebraic number fields $K$. Let $\rho \in \mathcal{D}(K)$ have non-zero algebraic eigenvalues $\lambda_1, \dots, \lambda_k \in K \cap (0, 1]$.
- If $\rho$ is pure, exactly one eigenvalue is 1 and the rest are 0. Then $S(\rho) = -1 \log 1 = 0 \in \mathbb{Q} \subset K$. Pure states have algebraic entropy $0$.
- If $\rho$ is mixed, at least two eigenvalues $\lambda_i, \lambda_j$ are strictly between 0 and 1. The expression for $S(\rho)$ becomes a linear combination:
  $$S(\rho) = -\sum_{i=1}^k \lambda_i \log \lambda_i$$
  By **Baker's Theorem on Linear Forms in Logarithms** (Alan Baker, 1966), if $\alpha_1, \dots, \alpha_m$ are algebraic numbers distinct from 0 and 1 whose logarithms are linearly independent over $\mathbb{Q}$, and $\beta_0, \beta_1, \dots, \beta_m$ are algebraic numbers not all zero, then:
  $$\beta_0 + \sum_{j=1}^m \beta_j \log \alpha_j \ne 0$$
  and is strictly transcendental.
- Consequently, for every mixed algebraic density matrix, the von Neumann entropy $S(\rho)$ is a transcendental number!
- **Thermodynamic Verdict:** A finite carrier $K$ strictly **refuses** mixed-state von Neumann entropy. The entropy cannot be computed or stored as an element of the carrier.

A thermal equilibrium state at inverse temperature $\beta$ is given by the KMS condition:
$$\rho_\beta = \frac{e^{-\beta H}}{\operatorname{Tr}(e^{-\beta H})}$$

### 4.3 The Second Law as a Decidable Algebraic Majorization Preorder

Let $p, q \in \mathbb{Q}^n$ be the ordered eigenvalue spectra of states $\rho$ and $\sigma$, sorted in descending order: $p_1 \ge p_2 \ge \dots \ge p_n$ and $q_1 \ge q_2 \ge \dots \ge q_n$.
State $\rho$ is said to **majorize** state $\sigma$ (written $\rho \succ \sigma$) if and only if:
$$\sum_{i=1}^k p_i \ge \sum_{i=1}^k q_i \quad \text{for all } k = 1, \dots, n-1, \quad \text{and} \quad \sum_{i=1}^n p_i = \sum_{i=1}^n q_i = 1.$$
